# 全局状态标签

用于卡片和详情摘要中的只读业务状态，不用于表格、筛选、计数或操作按钮。

声明式入口：`<span data-gaip-status-tag="success|warning">状态文案</span>`。

- 高度 24px、字号 12px、左右内边距 10px、胶囊圆角 12px。
- `success` 表示已完成或当前有效；`warning` 表示仍需处理。
- 标签不可点击且不提供 hover/选中态。需要用户操作时使用按钮。
- 当前消费者：方案中心“我的方案记录”的“已归属”和“待确认客户归属”。

详细边界见 [状态标签规范](../../docs/status-tag-spec.md)。
