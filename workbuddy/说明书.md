## 三、分析结论摘要

本项目是 **GAIP 原站的本地静态预览版**，核心架构为「入口薄壳 + Hash SPA 无刷新切换 + 频道资源预加载 + 三层 Mock 拦截」。详细分析见同目录下：

- [`项目结构分析.md`](./项目结构分析.md) —— 完整的目录、文件、机制说明
- [`文件清单与变更记录.md`](./文件清单与变更记录.md) —— workbuddy 文件夹内文件清单与变更记录

### 项目一句话总结

12 个同构 HTML 薄壳入口 → Umi Hash 路由无刷新切换 → 9 个频道（含 1 个虚拟频道"学习中心"）→ `channels.js` 唯一配置源 → `channel-features.js` 预加载频道资源 → `local-preview.js` 拦截 XHR/fetch 返回本地 Mock → `channel-entry-navigation.js` 同步地址栏文件名但不刷新页面。

### 分层架构

```
根目录 HTML 入口薄壳 (12 个，仅 title + 默认 Hash 不同)
        ↓
shared/ 共享层
  ├── config/channels.js        频道配置唯一源
  ├── scripts/ (6 个)           local-preview / channel-entry-navigation / channel-features
  │                             channel-regions / global-breadcrumb / learning-nav
  └── styles/ (3 个)            global-font / channel-foundation / learning-nav
        ↓
features/ 频道功能层
  ├── workspace/                工作台改版（行情跑马灯 + 资讯中心）
  ├── learning-center/          学习中心完整应用（1004 行 JS）
  ├── proposal-center/          方案中心改版（唯一通过 assets 预加载，724KB JS）
  ├── clues/                    线索中心 Mock + 布局补丁
  └── channel-data/             跨频道 Mock 数据
        ↓
AI Agent/ (AI 助手运行时，4 CSS + 2 JS + 素材/)
        ↓
web/ (Umi 构建产物，只读基线，149 个文件，严禁修改)
        ↓
assets/ (字体 + 学习图片 + 导航图标源 SVG)
        ↓
docs/ (7 篇文档) + qa/ (2 轮审计截图) + scripts/ (verify-local-navigation.sh)
```
