- **大小**：2643 字节
- **修改时间**：2026-08-13 17:03

这是一个 IIFE，向 `window.__GAIP_CHANNEL_CONFIG__` 注册全局频道配置。定义了 9 个频道的数组，每个频道包含 `key`/`label`/`route`/`entry`/`icon`/`type` 字段：

  { key: 'customer', label: '客户中心360', route: '/customer', entry: '客户中心360.html', icon: 'customer-360', type: 'master-detail' },

**关键设计：**
- 提供 `byKey`、`byRoute`、`byLabel` 三个查找索引，以及 `getByKey()`/`getByRoute()`/`getByLabel()` 三个查询方法

- **方案中心是唯一声明了 `assets` 的频道**：预加载 `proposal-center.css` 和 `proposal-center.js`
- induction 频道有别名 `aliases: ['薄荷入职指引']`（解决"引导"vs"指引"命名不一致问题）

### 2.2 `shared/scripts/` 脚本层（6 个文件）

#### (1) `channel-features.js` — 频道资源预加载器
- **大小**：2159B | **修改时间**：2026-08-13 17:03

**核心机制**：遍历 `channels.js` 中所有频道的 `assets.styles` 和 `assets.scripts`，在页面加载时统一预加载。因为 Hash SPA 路由不会重新读取另一个 HTML，所有频道改版资源必须在当前文档中可用。

```javascript
function loadStyle(path, channelKey) {
  var url = assetUrl(path);
  if (loaded[url] || document.querySelector('link[href="' + url + '"]')) return;
  loaded[url] = true;
  link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = url;
  link.setAttribute('data-gaip-feature', channelKey);
  document.head.appendChild(link);
}
// script 加载时设置 async = false 保证顺序执行
```

**额外功能**：通过 `webpackChunk.push` 暴露 `window.__GAIP_WEBPACK_REQUIRE__`，为改版模块提供运行时。最后在 `<html>` 上设置 `data-gaip-channel-features="ready"` 属性。

#### (2) `channel-entry-navigation.js` — 入口导航同步器
- **大小**：3316B | **修改时间**：2026-08-13 15:42

**核心机制**：监听 Hash 路由变化，通过 `history.replaceState()` 同步地址栏中的文件名（不触发整页刷新）。

**关键实现：**
- 通过 `document.currentScript.src` 计算入口根目录 `entryRoot`
- 生成 `documentSession` 标识（时间戳+随机数）
- 包装 `history.pushState` 和 `history.replaceState`，在每次调用后触发 `scheduleEntrySync()`
- 监听 `hashchange`、`popstate`、`gaip:learning-change` 事件
- `learningRequested()` 检测学习中心请求（通过 query 参数、`__GAIP_PAGE_OVERRIDE__` 或 `data-gaip-page` 属性）
- `file://` 协议下 `replaceState` 可能失败，设置 `data-gaip-entry-sync="unsupported"`

#### (3) `channel-regions.js` — 区域结构标识器
- **大小**：8176B | **修改时间**：2026-07-31 09:55

**核心机制**：为页面 DOM 元素打上 `data-gaip-region` 属性标签，建立稳定的结构语义层，避免依赖 CSS Modules 哈希类名。

**区域标签体系（20 个）**：`app-shell`、`app-header`、`brand`、`breadcrumb`、`user-actions`、`app-sidebar`、`primary-nav`、`app-main`、`channel-page`、`page-header`、`page-hero`、`page-nav`、`section-nav`、`page-actions`、`filter-toolbar`、`metric-overview`、`page-content`、`content-sidebar`、`content-main`、`ai-assistant-entry`

**每个频道的区域选择器映射**（`pageRegions` 对象）：为 9 个频道分别定义了 CSS 选择器到区域名的映射，例如：
```javascript
workspace: [
  ['page-hero', '[class*="banner___"]'],
  ['page-actions', '[class*="bannerActions___"]'],
  ['metric-overview', '[class*="statsRow___"]'],
  ['page-content', '[class*="panels___"]']

```

**工作方式**：使用 `MutationObserver` 监听整个文档变化，通过 `requestAnimationFrame` 调度 `applyStructureNames()`。暴露 `window.__GAIP_APPLY_STRUCTURE_NAMES__` 和 `window.__GAIP_REGION_LABELS__`。

#### (4) `global-breadcrumb.js` — 全局面包屑控制器
- **大小**：5922B | **修改时间**：2026-07-31 10:24

**核心机制**：统一管理所有频道的面包屑，规则为"工作台总览 / 当前频道 / 当前详情"。工作台首页只显示"工作台总览"，其他频道显示"工作台总览 / 当前频道"。

**关键 API：**
```javascript
window.__GAIP_BREADCRUMB__ = {
  refresh: scheduleRender,
  setDetail: function (pageKey, label, onParentClick) { ... },
  clearDetail: function (pageKey) { ... }
};
```

**签名机制**：使用 `data-gaip-breadcrumb-signature` 属性缓存当前面包屑结构签名，避免不必要的重渲染。支持学习中心虚拟频道的特殊处理（点击工作台链接时调用 `learningApi.closeForNavigation()`）。

## 10. 关键实现机制

### 10.1 Hash SPA 路由工作原理

**核心原则**：所有频道切换通过 Umi 的 Hash 路由完成，**绝不触发整页刷新**。

**工作流程**：
1. 用户打开任意 HTML 入口（如 `工作台.html`）
2. 内联脚本设置默认 Hash：`if (!location.hash) location.hash = '#/workspace';`
3. Umi 主包（`umi.0b0663b5.js`）读取 Hash，渲染对应 React 页面
4. 用户点击侧栏菜单 → Umi 内部调用 `history.pushState()` 修改 Hash
5. `channel-entry-navigation.js` 拦截 `pushState`/`replaceState`，通过 `history.replaceState()` 同步地址栏文件名（如 `工作台.html` → `方案中心.html`），但不触发导航
6. `channel-regions.js` 监听 Hash 变化，重新标记页面区域
7. `global-breadcrumb.js` 更新面包屑
8. `learning-nav.js` 更新菜单选中态

**学习中心特殊处理**：学习中心是虚拟频道，Hash 路由仍为 `#/workspace`，但附加 query `?gaip-channel=learning`。`learningRequested()` 函数通过三种方式检测：query 参数、`window.__GAIP_PAGE_OVERRIDE__`、`document.body data-gaip-page` 属性。

### 10.2 频道资源预加载机制（channel-features.js）

**问题背景**：Hash SPA 路由不重新加载 HTML，因此所有频道改版资源必须在首次加载时就全部可用。

**解决方案**：
1. `channels.js` 中每个频道可声明 `assets: { styles: [...], scripts: [...] }`
2. `channel-features.js` 遍历所有频道，对每个声明的资源动态创建 `<link>` / `<script>` 标签
3. 使用 `loaded` 对象去重，避免重复加载
4. 脚本设置 `async = false` 保证执行顺序
5. 加载完成后在 `<html>` 设置 `data-gaip-channel-features="ready"`

**当前状态**：只有 `proposal` 频道通过此机制加载（`proposal-center.css` + `proposal-center.js`）。其他频道（workspace/learning-center/clues）的资源直接在所有 HTML 中硬编码引用。

### 10.3 本地 Mock 数据机制

**三层 Mock 架构**：

```
local-preview.js (核心调度器)
  ├── __GAIP_AGENT_MOCK__ (AI Agent 对话 Mock)
  │     └── AI Agent/AI Agent本地Mock.js
  ├── __GAIP_CLUE_MOCK__ (线索中心 Mock)
  │     └── features/clues/mock-data.js
  ├── __GAIP_CHANNEL_DATA_MOCK__ (频道数据 Mock)
  │     └── features/channel-data/mock-data.js
  └── 内置静态响应 (产品/活动/工作台/字典等)
```

**请求处理流程**：
1. `local-preview.js` 替换 `window.XMLHttpRequest` 和 `window.fetch`
2. 每个 XHR/fetch 请求被拦截，URL 传入 `dataFor(url, request)`
3. `dataFor()` 按优先级依次查询三个 Mock 模块的 `dataFor()` 方法
4. 若都未命中，匹配内置的 URL 模式返回静态数据
5. 统一包装为 `{ code: '20000', message: 'success', data: ... }` 格式
6. 通过 `setTimeout(..., 0)` 异步返回（模拟网络延迟）

**Webpack 模块冲突修复**：`local-preview.js` 在 Umi 主包执行前，通过 `webpackChunk.push` 预注册模块 90894（产品/活动枚举常量），解决"先进入活动中心再切换到产品中心时 fV.CN 报错"的分包加载顺序问题。

**登录 Mock**：`window.initAlicom4` 被替换为直接返回验证成功的假滑块 SDK，任意非空账号密码即可登录。

### 10.4 入口导航同步机制（channel-entry-navigation.js）

**目标**：地址栏文件名始终与当前频道对应，但不触发整页刷新。

**实现步骤**：
1. 脚本加载时通过 `document.currentScript.src` 计算 `entryRoot`（项目根目录 URL）
2. 从 `channels.js` 构建 `routeEntries` 映射（route → entry 文件名）
3. 包装 `history.pushState` 和 `history.replaceState`，每次调用后触发 `scheduleEntrySync()`
4. `syncEntryPath()` 根据当前 Hash 路由查找对应的 entry 文件名
5. 若当前 `location.pathname` 与目标不同，调用 `history.replaceState()` 修改地址栏
6. `file://` 协议下 `replaceState` 可能抛异常，捕获后设置 `data-gaip-entry-sync="unsupported"`

**事件监听**：`hashchange`、`popstate`、`gaip:learning-change`，以及 `DOMContentLoaded`（如果文档还在加载中）。

**学习中心特殊处理**：`entryFile()` 函数检测 `learningRequested()`，若为 true 则返回 `学习中心.html`，否则按正常路由查找。

**文档会话标识**：生成 `documentSession`（时间戳+随机数）并设置到 `data-gaip-document-session` 属性，可用于调试和追踪。

## 12. 架构总结

### 核心设计理念
