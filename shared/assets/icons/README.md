# 图标维护目录

所有自有运行图标源集中在本目录；已经由用户选定的同用途版本使用单一维护源，其余版本继续保留，尚未确定统一设计风格。

- `operations/`：搜索、关闭、上传、翻页等操作。
- `navigation/`：导航。
- `status/`：状态及标签，含 AI 状态动效 JSON；图片纹理、视频和 Lottie 运行库仍按媒体/依赖维护。
- `forms/`：表单、组织树及 CSS 绘制规则。
- `business/`：频道和业务图形。
- `brand/`：品牌及货币标识。
- `third-party/ant-design/`：实际接入的第三方本地 SVG。

`registry.json` 登记原位置、维护源、消费者和生成绑定。编辑 SVG/CSS 原文件后运行 `npm run build:icons`；不要手改 `local-icons.generated.js`、模板中的 @gaip-icon 区段或业务脚本中的生成缓存。SVG 默认保持原路径、画布、描边与颜色；增加文件须登记来源和实际消费者，合并前逐个替换引用再删除旧源。

第三方 SVG 生成本地树数据，由已有 React/Ant 组件读取；有限动态图形同样从完整 SVG 生成缓存，file 预览无需 fetch。CSS 规则保留消费者中的原顺序，由中央源同步；弹窗关闭遮罩的 data 副本保留 file 兼容性。原站 web 与历史归档只作只读基线，不属于新的维护源。Lucide 来源许可继续保存在 components/table/ICONS-LICENSE.txt。

用户单独输入编号或“合并编号”，表示保留该版本并合并同组其余版本；限定范围优先。`reviewMerges` 保存已确认关系，`mergedFrom` 仅追溯退出来源；Ant 模块别名仍可调用原组件，绘图来自保留 SVG。模板合并绑定保留宿主尺寸和可访问属性；原编号不重排，旧号可在预览搜索保留项。2026-10-01 当前登记 495 个维护源、69 个 Ant 模块别名，预览 260 项；已完成10组SVG合并和1组CSS绘图合并，08-1至08-3全部统一为08-1，02组统一为02-2，03-1至03-7全部统一为03-2。

生成后执行 `npm run check:standards` 和 `npm run test:icons`；显示范围与验收边界见 `docs/icon-catalog-spec.md`。
