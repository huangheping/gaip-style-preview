# 全局筛选栏规范 · V1

2026-09-09，组件已在独立 Chromium 渲染中检查，来源课程管理整页仍待现场验收，未部署。全局能力不等于全站自动替换；首个使用位置为学习中心的课程管理。

## 结构与视觉

- 筛选栏自己管理输入、原生数据节点、自绘下拉、搜索/清除图标和弹出面板。`mount` 在自身form声明`data-gaip-modal-controls="exclude"`及`data-gaip-form-field="exclude"`，嵌入信息弹窗时不再接受通用表单增强。只排除筛选栏内部，不能禁用整个弹窗的普通表单控件增强。

- 字段宽度按类型设上限：普通单选/单日期基础220px、最大280px；多选280/320px；搜索或`wide:true`为300/360px；日期与数字区间420/480px。开关按内容占位，不参与剩余空间拉伸。区间两端等宽，更多字段独占一行时也不无限撑满。
- 根据筛选栏自身内容宽度适配（命名容器`gaip-filter`），不是只看窗口：容器≤640px时非开关字段占满一行，保留区间组合，开关保持内容宽度。更宽容器按现有顺序自然换行，空白可保留，操作区继续靠右。窗口≤640px仍沿用原内边距。

- 一套 `shared/scripts/global-filter-bar.js` + `shared/styles/global-filter-bar.css`，样式只在 `.gaip-filter-bar` 内生效；页面不再自行拼筛选控件皮肤。
- 默认控件 40px 高，使用项目共享字体、品牌色 `--gaip-color-brand`、文字色和 4px 控件圆角。标签在上，标签与控件相距 8px；横向间距24px，换行间距16px，容器内边距20px，小屏16px。
- 控件按配置顺序排列；不足时换行，不挤压开关、不省略字段标签。范围字段可占更宽空间；重置/查询属于筛选栏，不与新增/导出等页面操作混排。
- 状态覆盖：默认、悬停、聚焦、选中、禁用、错误、空值。输入控件以边框区分聚焦，按钮和开关保留键盘焦点提示。
- 下拉箭头、搜索、清空使用已有共享 SVG，日期复用弹窗的 `shared/assets/modal-calendar.svg`。多选复用 `__GAIP_MULTI_SELECT__`；标签文本单独省略，超额计数不压缩；普通字段不足最小宽度时换行。
- 清除使用同一个 `modal-clear.svg`，可见图形16px、点击区域24px，搜索/筛选多选/独立多选与弹窗一致；不可用文字×或缩放按钮盒子替代图形尺寸。保持原显隐和清除条件。
- 单选与日期使用共享筛选组件自绘面板，不再展示系统弹出菜单。面板统一白底、边框、阴影和选中状态；单选选中关闭，多选连续勾选不关闭，点击外部或 Escape 关闭。多选更新保留选项节点及焦点，避免点击冒泡时将已删除节点误判为外部。
- 日期空值为“年/月/日”，有值显示 YYYY/MM/DD，输出仍为 YYYY-MM-DD；由全局日期组件统一提供年月切换、方向键跨月、今天及相邻月份日期，清除位于既有选择条尾部。日历规范见 `docs/date-picker-spec.md`。保留日期 min/max/step 校验，超出范围的日期和“今天”禁用。原生数据节点只负责值与校验，不承担可见样式。
- 单选/日期面板使用 Popover 顶层（不支持时回退 fixed），随滚动/缩放重新定位；隐藏、禁用、销毁筛选项时关闭面板并清理监听。多选沿用原有锚定展开结构。

## 可选控件

| type | 内容 | 值 | 适用场景 |
| --- | --- | --- | --- |
| search | 搜索＋独立清空 | 字符串 | 名称、编号、关键字 |
| select | 单选下拉 | 字符串，空串为不限 | 课程状态、单一群组 |
| treeSelect | 可搜索树形单选 | 稳定节点ID，空串为不限 | 所属组织；搜索仅筛选下拉节点，不直接改变业务结果 |
| multiSelect | 折叠式多选 | 字符串数组，空数组为不限 | 多个群组、标签；默认展示前2项，其余 `+ N ...` |
| switch | 二态开关 | boolean | “只看必修课”；关闭表示不限，不等于只看非必修 |
| date | 单日 | YYYY-MM-DD | 指定日期 |
| dateRange | 日期范围 | [开始,结束] | 创建/更新时间区间 |
| numberRange | 数字范围 | [最小,最大] | 数量、金额；支持 min/max/step |

重置、查询、更多筛选均为可配置操作。单选已有“全部”选项时不重复添加；无空值选项则补“全部”。无效单选值和多选中不存在的选项会清除，避免不可见的条件影响结果。

## 显隐与生效规则

1. **页面配置显隐**：`visible:false` 不展示、不占位、不输出该键，并清除当前值；再展示时为空，不偷偷恢复旧条件。可用 `visible(values)` 做无循环依赖的业务联动。
2. **更多展开/收起**：`advanced:true` 只改变展示，不改变有效值；收起时在“更多筛选”按钮提示已生效项数。不要把 `visible:false` 当成折叠。
3. **禁用**：`disabled:true` 或函数保持可见但不可交互，值仍参与筛选；适合必须固定的范围。它不是安全鉴权，后端仍须校验权限。
4. **重置**：恢复所有字段的 `defaultValue`，未声明时恢复空值/false；配置隐藏的字段始终排除。任一可见字段偏离这一重置基准时，重置按钮使用 `#2F3640` 底色和白色文字；恢复基准后回到普通状态。搜索比较使用去除首尾空格后的有效值，页面初始默认条件不误标为用户改动。重置取消待执行搜索，统一发一次结果通知。
5. **即时模式** `mode:'instant'`：下拉/开关立即通知，搜索默认250ms延迟；中文拼音组合未结束时不查询，Enter立即提交。课程管理维持此模式，只替换外观和实现。
6. **提交模式** `mode:'submit'`：改字段不调用 `onChange`，点击查询/Enter才调用 `onSubmit`；`onReset`由页面决定重置后是否查询。模式不要在同一页面里不加说明地混用。
7. 日期/数字允许单端范围；双端时开始不得超过结束。非法范围显示内联错误并阻止查询，不擅自交换用户输入；提交时展开并聚焦首错。
8. 翻页、数据请求、筛选表达式、权限由页面负责。组件只收集条件，不发网络请求、不写localStorage、不替业务定义“群组多选AND/OR”等规则。

当前按**页面配置**显隐实现，未给真实使用人新增“自定义筛选项”入口；目录里的显隐勾选仅用于演示配置。

## 接入示例

在频道 `shared/config/channels.js` 的资源数组里登记：`global-multi-select.css/js` → `global-filter-bar.css/js` → 页面脚本。组件目录也使用同一来源。

```js
const bar = window.__GAIP_FILTER_BAR__.mount(root, {
  label: '课程筛选',
  mode: 'instant',
  values: { q: '', required: false },
  actions: { reset: true, submit: false, more: true },
  fields: [
    { key: 'q', type: 'search', label: '课程名称', wide: true },
    { key: 'status', type: 'select', label: '课程状态',
      options: [{ value: '', label: '全部状态' }, { value: 'published', label: '已上架' }] },
    { key: 'groups', type: 'multiSelect', label: '学习群组', visible: false,
      options: ['香港业务', '新加坡业务'] },
    { key: 'required', type: 'switch', label: '必修属性', text: '只看必修课' },
    { key: 'period', type: 'dateRange', label: '创建日期', advanced: true }
  ],
  onChange(values, meta) { /* 页码归一并更新结果区，不重建筛选栏 */ }
});
bar.setVisible('groups', true);
bar.setDisabled('status', true);
bar.setValue({ q: '课程名称' }); // 默认通知；第二参 {silent:true} 可抑制
bar.getValues();
bar.reset();
bar.destroy(); // 离开页面必须清理搜索延迟及多选的document监听
```

字段 `key` 唯一且稳定，`fields` 顺序即展示顺序。宽字段用 `wide:true`。单选/多选 `options` 支持字符串或 `{value,label}`。日期/数字的原生边界使用 `min/max/step`，名称长度可用 `maxLength`。

### 组织树单选（2026-09-10）

主控件为可编辑的组合输入框：点击展开组织树，直接在该输入框输入名称筛选节点；面板不再放第二个搜索框。搜索时保持输入焦点，中文输入法组合完成后更新结果；输入关键词不提交业务筛选，选择节点才回填组织路径并生效。Escape、点击外部或失焦收起时丢弃未确认关键词、恢复已选名称；清除按钮恢复不限，箭头与清除图标不重叠。方向键可进入树选择，其他单选/多选行为不变。学情主页面、课程学习详情和组件库均复用同一实现。

显式加载`shared/scripts/organization-store.js`、`organization-tree.js`和`shared/styles/organization-tree.css`。字段配置`{key:'org',type:'treeSelect',label:'所属组织',nodes:()=>nodes}`；节点为`{id,parent,name,path}`，支持静态数组或每次打开读取的函数。值是稳定ID，不是路径文字。空值入口使用placeholder文案；树内搜索保留匹配节点及其祖先、自动展开匹配路径；展开箭头和选择分开操作，选择后关闭。支持上下/左右/Home/End/Enter键与Escape关闭、焦点返回，清空搜索不清除原选择。显隐、禁用、重置、销毁与其他筛选项一致。

组件只负责节点选择；学情页通过`organizationNodes()`提供权限内的节点，用`matchesOrg()`执行父节点及后代过滤。组织架构主树与筛选下拉共用`__GAIP_ORG_TREE__.node`，主树保留原管理菜单和排版，选择器为紧凑密度；二者数据均取`__GAIP_ORGANIZATION__.sets`。配置中心原批量导入/调整节点树同样读取该数据，不改变其既有操作。

实例隔离、重复mount会销毁旧实例。对值/显隐/禁用使用API；不要从外部只写 `display:none`，否则有效条件与视觉不一致。`gaip:filter-change`事件包含 values/reason/mode，提交模式的该事件可用于展示草稿，不可不看mode就请求数据；业务优先用 onChange/onSubmit 回调。

## 首次落地与边界

- 课程管理按“搜索 → 学习群组 → 课程状态 → 只看必修课”排列四项；学习群组使用共享多选，未选为不限，所选群组按OR匹配课程配置，单门课程不重复。保留“全部用户”选项专门匹配群组配置为all的课程，不把它当作清空筛选。重置恢复空数组；不启用创建日期，无高级字段时组件自动隐藏更多按钮。日期能力仍供其他页面使用。顶部操作和表格排序不变。
- 全局组件目录新增“可配置筛选栏”，原条目保留；示例包含全部类型、更多筛选和显隐演示，直接调用共享组件。
- 组织搜索下拉默认可见，无需展开更多筛选；“展示组织搜索下拉”开关演示配置显隐，隐藏时清除组织条件。直接输入、下拉节点与学情页面同源，无独立演示控件。
- 学情管理已显式接入：两维度统计、详情抽屉、学情日志搜索复用同源筛选栏；原群组单选与必修三态由各页配置保留，不照搬课程管理的多选/开关业务含义。其他频道未批量替换；既有弹窗控件共享层不受影响。
- `scripts/test-filter-bar.cjs`覆盖组合输入、显隐/重置/范围校验/提交/清理、真实目录同源调用；学习列表与V1.1回归另跑。
- `scripts/test-filter-bar-browser.cjs` 使用真实组件/目录源码在独立 Chromium 中检查连续勾选、外部点击/Escape、自绘单选、日期切月/今天/清除，以及1440/1100/800/480px宽度的溢出和日期面板边界；截图已人工查看。此检查不代表真实课程管理整页或其他浏览器验收，不访问线上、不通过HTTP绕过file限制。
