# 本地浏览器行为回归清单

状态：2026-09-07 已收到四项用户手工确认；其余条件仍待验证。本文件不是自动化通过报告，具体证据与范围见 [当前变更记录](../knowledge/变更/当前未发布变更.md#2026-09-07-用户手工回归确认)。

依据：[OpenAI 的复现与验证指导](https://learn.chatgpt.com/docs/prompting#prompting-codex)、[Playwright 的用户可见行为与测试隔离原则](https://playwright.dev/docs/best-practices)。以下 GAIP 路径和验收值来自项目契约，不是官方通用参数。

## 准备

- 记录 Git 提交及相关未提交改动、浏览器版本、视口、完整入口与 Hash。
- 使用独立测试标签页或浏览器配置，避免真实工作中的输入被修改；只操作本地 Mock，不提交真实线上数据。
- 原始交付仍是 `file://`。工具若明确拒绝该 URL，不得换协议或技术绕过；留作允许访问的浏览器现场验证。
- 每条场景独立打开指定入口，不依赖上一条的筛选或登录状态。控制台与 Network 保留日志，区分原有错误和本次新增错误。

## 场景与通过条件

| 场景 | 用户操作 | 通过条件 | 结果 |
| --- | --- | --- | --- |
| 原生频道跨入口 | 打开 `工作台.html#/workspace`，点方案中心，再点活动中心 | 每次内容、面包屑、当前态与 Hash 一致；无新主文档请求，不只是 URL 改了 | 未验证 |
| 虚拟入口离开与刷新 | 打开 `财富值中心.html#/workspace?gaip-channel=wealth&gaip-view=import-workbench`，点工作台总览，然后刷新 | 点击时主文档不重新加载；刷新后仍是工作台，不回导入工作台 | 部分确认：用户从该文件名下的方案中心切到工作台，刷新保留；完整初始路径与无刷新未验证 |
| 父项纯开合 | 财富值导入工作台中，点击配置中心父项，再按 Enter / Space 开合、Esc 收起 | Hash 和财富值内容不变；父项只控制子菜单；焦点与 aria-expanded 一致 | 未验证 |
| 弹窗关闭后的底层点击 | 进入配置中心 → 组织架构，点页面右上角操作日志，关闭后点方案中心 | 真实日志可见；关闭后无透明宿主拦截；底层导航实际收到点击并切换内容 | 用户手工确认关闭后可导航；未采集命中节点 |
| 原生 Esc 与再次打开 | 重新进入组织架构，打开操作日志，按 Esc，再点同一入口 | Esc 关闭并恢复焦点；再次打开正常，只有一个活动弹层，不残留重复遮罩 | 用户确认 Esc 关闭和再开；焦点及遮罩数量未核验 |
| 登录与 AI 入口 | 独立打开 `登录.html#/login`，输入本地测试账号密码，进入后通过既有日期入口切换 V1/V2，再跨频道切换 | 入口版本正常切换；无重复入口；跨频道后仍可切换；视频/WebGL 另记视觉结果 | 用户确认登录后及跨频道版本切换；入口数量和视频/WebGL 未核验 |

等待可见控件/内容完成挂载后再操作；不要以固定睡眠后“没报错”作为通过条件。关闭弹窗时应通过真实鼠标点击与键盘检验，不以脚本 `.click()` 代替命中测试。失败时记录实际命中/遮挡节点与控制台输出，不能只截图说成功。

“Hash 无刷新”指导航阶段没有新的主文档加载，不要求异步 JS/CSS/图片请求为零。手动刷新阶段预期有一次主文档加载，但必须保持当前路由。若使用 DevTools 检查命中节点，它只作为诊断证据，仍要实际操作核对结果。
