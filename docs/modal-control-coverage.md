# 弹窗内部表单控件覆盖清单

本轮：2026-09-08。本清单说明源码接入范围，不代表全部弹窗已完成真实浏览器视觉验收。

## 唯一来源与边界

- 普通输入、文本域、标签及帮助/错误提示：`shared/styles/global-modal.css`。
- 复合控件、状态主题、清除/展开图标、选择面板：`shared/styles/modal-controls.css`。
- 弹窗识别、外置面板归属、原生选择控件适配：`shared/scripts/modal-controls.js`。
- 预览和业务入口加载同一套文件；不维护预览专用表单 DOM/CSS。
- 仅 `.gaip-modal-controls` 所属弹窗、明确属于弹窗的 `.gaip-modal-popup` 展开面板。页面表单、抽屉、AI Agent 主面板不接入。弹窗外的日志页面仍使用自己的样式及原生日期面板。
- Ant 选择器保留原本组件和事件；原生 select/date/time 的数据控件保留，共享面板回写原控件并触发 input/change，继续使用原 required/min/max/step 校验。

## 状态契约

多行输入的来源核验、固定规则和新来源接入方式见[多行输入组件验收](modal-textarea-acceptance.md)。23/24新增原客户组件与项目自带Ant的DOM测试；自动增高/无计数变体保持业务语义，浏览器视觉仍待验收。

### 确认/表单内部组合部件

- 唯一入口为 `global-modal.js` 的 `adoptInteriors`，仅给两类真实节点增加 `.gaip-kit-*`；样式在 `global-modal.css`，参数见 `design-changes/modal-interiors.json`。
- 已接入普通/树选择列表、单选多选卡片、字段网格、帮助/错误/空态、提示区、计数文本域、批量导入步骤/附件/校验表格/结果摘要及操作栏。保留各业务的布局结构、状态、滚动拥有者和事件。
- 容器与控件使用分层圆角 token；圆形 Radio、步骤标记不使用方框圆角。列表和树共用框体与文字，不合并树缩进和普通行结构。
- 新来源可在现有节点声明 `data-gaip-modal-part="list"`、`list-row`、`notice`、`error`、`section`、`summary` 等契约；类名接入映射见 `adoptInteriors`。不要在预览另写同款部件。
- 18、33、34 保留原计数节点及自动高度；为计数预留独立底部行。15 通过真实控制器验证上传示例→校验→结果→再次导入，13 使用真实设置管理员入口验证已填充卡片。
- 计数框续检：18/23/24/33/34的普通内层padding规则排除计数变体；回归比较实际匹配的padding声明优先级及顺序，不能只检查“存在目标规则”。公告三语言填写到上限时仍更新原计数节点。
- 日期时间图标按控件用途区分：24两个日期字段原`DatePicker.suffixIcon`使用自定义`selectArrow___R46ag`，现在与其他Ant日期、日期范围共用日历；纯时间保留源`clock-circle`语义并使用时钟。原生date/datetime-local使用日历、time使用时钟。两类均直接绘制用户附件的本地共享副本，不使用外部mask；参数见视觉台账。24沟通方式及其他Ant/原生/多选的普通Select仍使用下箭头；树展开图标不变。原组件节点和事件不替换，不凭任意类名或占位文案推断自定义时间控件语义。
- 图标回归重建24真实后缀宿主，并覆盖Ant日期/范围/纯时间、原生date/time/datetime-local、普通Select不误替换及页面排除；附件几何/颜色和样式引用有源码断言，原生日期范围、时间步长与原事件回归保留。这些是源码/DOM检查，不代替视觉验收。

- 表单单行文本/搜索清除：有内容且 hover/focus 时显示；空值、禁用、只读不显示。存在源清除节点则复用其事件，没有则新增兄弟按钮，通过原输入 setter 及 input/change 更新，不包裹或移动输入节点。旧源未发送输入通知时，微任务同步清除显示；补充键盘操作。数字保留步进器，多行保留计数和自动增高，必选下拉不新增空值。
- 04、15、16 搜索框共用前缀图标槽及图文间距；原图标节点保留但不占位，浏览器原生 search 清除指示器关闭，避免双图标。独立输入的清除按钮跟随字段及宿主 ResizeObserver 更新位置，控件离开弹窗后清理增强。
- Ant 与原生适配的选项密度、日期格/时间行尺寸及 hover/focus/selected/disabled 由共享样式拥有；不把树、日历与单列选项强制改成相同结构。下拉空值占位、展开焦点、日期只读及原生日期不可选的优先级补齐。
- 普通 hover 和按下不代替 focus；键盘聚焦保留可见指示。
- 单选、多选、树勾选和半选使用独立选择色 token，不连带修改保存按钮主色；错误状态不能被 hover/focus 覆盖；禁用状态不能被选中/hover 覆盖。具体参数仅维护在视觉台账。
- 15批量导入目标节点不再显示行尾勾号，节点前的圆点与10/16共用Radio基础、选中、hover/focus和禁用声明；保留树行`aria-selected`及原单选事件，不把装饰圆点变成嵌套表单字段。展开箭头保持独立，16仍为完整列表。真实源回归覆盖圆点点击、展开不改选择、渠道重绘及关闭重开。
- 只读字段保留查看和键盘聚焦，不打开修改面板。
- 原生选择面板支持 Esc 只关闭当前面板、Tab 返回正常字段顺序、关闭父弹窗清理面板；选择列表上下键，日历方向键，时间列上下键。
- 字段值、清除显示条件、数据验证与保存仍由业务拥有。相同视觉不等于把不同业务表单重写为相同内容。

## 未合并的个性化内容与验收缺口

- 2026-09-08 错位续修：原生适配面板保留在所属弹窗 DOM 内，优先使用 manual Popover 顶层逃离祖先 transform/overflow；不支持时按包含块的实际原点和缩放换算坐标（老引擎仍可能受祖先 overflow 裁切）。Ant 自有展开面板不搬动，继续由 Ant 定位。
- 22 新增线索：共享 grid 已居中，旧源仍保留 translateY(-50%)，共享定位层仅为这个旧组件取消重复位移；不清空所有 Ant 动画。
- 图标：清除原 SVG 不再占用布局空间；清除和下拉只用一种垂直居中规则。隐藏条件、清除事件仍由源组件负责；单选下拉的搜索框/文字行盒统一到外框高度，分页保持紧凑高度。
- 续修验证涵盖包含块平移/缩放的坐标模拟、Popover 分支、图标规则、22 遗留 transform 覆盖、颜色 token 与既有 DOM 回归；这些不是浏览器视觉验收。

- 业务图表、附件预览、长文排版、流程步骤内容、语义状态标签颜色、特殊列布局不强制改成统一表单。它们不是同一个控件的重复样式。
- Ant Switch 提供了主题兼容规则，但本轮未确认当前全部弹窗中是否存在实际开关实例，不将兼容规则称为已验收实例。
- 源码/DOM 检查涵盖真实工厂及旧源结构、原生选择事件、日期范围、时间步长、面板归属、禁用、关闭清理和页面排除；不会证明各频道动态 Ant Portal 在所有实际交互时机下均无遗漏。
- 本地 `file://` 浏览器自动化被拒绝，真实图标对齐、面板定位、滚动、响应式和各状态颜色仍需刷新来源与预览进行人工验收。没有绕过限制。
- 新的业务专用控件需要接入已有选择器/语义属性；无法仅凭任意自定义类名自动推断其语义。新增弹窗仍走源登记流程。

视觉参数唯一台账：`design-changes/modal-controls.json`（线上基准未知，源码级验证）。
