# GAIP 频道页面结构命名规范

## 目的

频道页面继续使用原有 React 与 CSS Modules 代码。本规范通过稳定的
`data-gaip-region` 属性和 `gaip-region--*` 类名描述页面结构，避免在统一
样式、页面审计和沟通时直接依赖 `header___tcVAl`、`pageContainer___Npetg`
一类会随构建变化的哈希类名。

结构标识仅用于语义识别和稳定选取，不附带视觉样式，不改变原有布局和交互。

## 应用框架

| 中文名称 | 稳定名称 | 说明 |
| --- | --- | --- |
| 应用框架 | `app-shell` | 顶栏、侧栏、主内容区的共同容器 |
| 全局顶栏 | `app-header` | Logo、面包屑、日期及用户操作 |
| 品牌标识 | `brand` | GLORY / GAIP Logo |
| 面包屑 | `breadcrumb` | 当前频道路径 |
| 用户操作区 | `user-actions` | 日期、头像、账号及退出操作 |
| 主导航侧栏 | `app-sidebar` | 左侧完整侧栏容器 |
| 主导航 | `primary-nav` | 侧栏中的一级频道菜单 |
| 主内容区 | `app-main` | 右侧承载频道页面的公共区域 |
| AI 助手入口 | `ai-assistant-entry` | 全局悬浮 AI 入口 |

当前主导航包含：工作台总览、客户中心360、保单列表、方案中心、产品中心、
活动中心、财富值中心、薄荷入职引导、线索中心、学习中心。财富值中心展开后
包含导入工作台、导入记录和我的财富值三个子频道。

全局面包屑以工作台总览为根节点：工作台首页只显示 `工作台总览`，其他频道显示
`工作台总览 / 当前频道`，详情页继续追加当前详情。根节点和中间节点可返回，当前
节点不可点击并使用 `aria-current="page"`。

学习中心作为应用内扩展频道接入：切换时沿用当前页面的全局顶栏和主导航侧栏。
财富值中心同样作为应用内扩展频道接入，并通过 Hash 查询参数保持子频道状态。
全部主导航频道继续使用 Umi Hash 路由无刷新切换；地址栏文件名通过 History API
同步为当前 `样式优化html/` 目录下对应的 HTML，且不触发文档重载。登录成功进入
工作台时也使用同一套目录锁定与地址同步规则，避免与工作区内其他同名页面混用。

## 频道页面

| 中文名称 | 稳定名称 | 适用场景 |
| --- | --- | --- |
| 频道页面 | `channel-page` | 每个频道最外层容器 |
| 频道页头 | `page-header` | 频道标题、说明及页头操作 |
| 主视觉区 | `page-hero` | 带图片或重点信息表达的顶部区域 |
| 频道导航 | `page-nav` | 产品分类、线索状态、入职章节等一级页内导航 |
| 分区导航 | `section-nav` | 章节之下的二级页内导航 |
| 页面操作区 | `page-actions` | 搜索、新增、导出等主要操作 |
| 筛选工具栏 | `filter-toolbar` | 下拉筛选、条件筛选及清空筛选 |
| 指标概览 | `metric-overview` | 统计卡片或核心数字概览 |
| 页面内容 | `page-content` | 频道核心内容的共同容器 |
| 内容侧栏 | `content-sidebar` | 页面内部的分类、列表或辅助导航侧栏 |
| 内容主体 | `content-main` | 列表、表格、详情或卡片主体 |

## 使用方式

统一样式优先使用稳定区域名称：

```css
[data-gaip-region="app-header"] {
  /* 全局顶栏样式 */
}

.gaip-region--app-sidebar {
  /* 主导航侧栏样式 */
}

body[data-gaip-page="clues"] [data-gaip-region="filter-toolbar"] {
  /* 只作用于线索中心的筛选工具栏 */
}
```

调试时可以在浏览器控制台查看：

```js
document.querySelectorAll('[data-gaip-region]');
window.__GAIP_REGION_LABELS__;
```

## 约束

1. “全局顶栏”只表示跨频道共享的顶部区域；频道自己的顶部结构叫“频道页头”。
2. 只有承担主视觉或营销表达的区域才叫“主视觉区”，不把所有顶部区域统称为 Banner。
3. “主导航侧栏”表示整块左侧容器，“主导航”只表示其中的频道菜单。
4. 新增页面区域时优先复用本规范；确实出现新语义后再扩充名称。
5. 不直接修改或依赖构建产物中的哈希后缀。
