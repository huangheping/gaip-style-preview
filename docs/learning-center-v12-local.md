# 学习中心 V1.2 直播 Banner：本地实现

> 当前状态（2026-09-17）：根据用户新确认，首页使用内容区横向直播卡片，单场半宽靠左、双场并排、更多按组切换。未恢复此前标题区轮播试版；原课程、学习记录均保留。

更新：2026-09-17。仅修改 Documents 原项目，未提交、未发布；不修改桌面重构副本。

## 依据和范围

- 产品依据：`产品文档/【先等等】GAIP-学习中心_V1.2直播.zip` 内产品说明。
- 用户确认：保存草稿不会自动上架；需再点“上架”并确认定时或立即上架。图片沿用 750:320 比例。诺学堂的上传与播放机制不在本项目范围。
- 用户追加要求后，一次性补入 8 条带“【示例】”前缀的直播 Mock：3 已上架、3 草稿（1 已排期、1 待完善）、2 已下架；首页超级管理员可按组查看上架横卡。配套 15 条模拟日志，操作人为“示例管理员”。进入学习中心 → 直播管理仍可自行新增；自行保存草稿不会自动上架。
- 批次 `live-examples-20260916` 使用固定 ID 和持久化标记，刷新不重复、删除不恢复、已编辑内容不覆盖；已有同名/同目标记录会跳过对应示例。图片复用现有本地课程素材，仅作占位；示例 ID 不是真实直播，链接草稿使用 example.com。时间以首次生成时间为基准，不随刷新延期；已上架示例 14 天后到期。
- 保持原课程列表、课程数据、学习进度和课程编辑流程不变。

## 已实现流程

- 首页直播横卡位于课程同一滚动区，桌面原头部高度不变；管理入口仍在标题栏右侧，窄屏换行。单场与双场同宽靠左（左图、右标题简介及状态）、双场并排，超过两场手动按组切换；最后一组仅一场时同样半宽靠左。窄容器改为单列，图片保持 750:320、完整显示。无可见直播时整区连同课程分区标题一起收起，不保留空白。
- 标签始终为“直播”，旁边依据独立 `liveStartAt` 展示倒计时，到点在原位置替换为“直播中”，每秒检查但只更新变化文字；未配置为“开播时间待定”。此为本地按开播时间演示，真实播放状态未接入；`startAt/endAt` 仅控制广告上下架，不能替代实际开播时间。
- 新增公开字段 `publicTitle`（最多 100 字）、`summary`（选填，最多 200 字）、`liveStartAt`（实际开播时间），由原共享编辑弹窗配置；不将仅后台名称用作公开标题。兼容旧数据：缺少标题显示“直播活动”，缺少开播时间不误标直播中。已上架字段锁定规则保留，需在草稿阶段填写。
- 展示示例批次 `live-presentation-20260917` 只给三条已知、带 mock 标记的示例补缺失字段，不覆盖已填写字段，不恢复被删除记录，不改课程或学习数据。示例图仍复用旧本地素材，非 750:320 图片可能出现内侧留白；正式同尺寸素材无需裁切。
- 首页不再展示 Mock 版本和预览身份选择栏；本地应用首次挂载选择已有的有效超级管理员，刷新后恢复默认。保留领域权限判断，不清空课程、学习记录或日志；这不是生产鉴权方案。
- 管理入口：超级管理员和本地 `live` 角色；列表复用全局筛选器、表格、状态标签，按产品要求不分页。筛选名称和状态；链接通过“查看”气泡展示，长 URL 可折行、滚动。
- 表单：名称、图片、对接类型、直播 ID / 链接、学习群组、上架时间、下架时间。使用共享弹窗外壳、字段反馈、多选、日期/时间选择器和确认组件；5 个新增场景已源登记。
- 草稿仅校验名称，50 字内、未删除记录中唯一。确认上架时校验其他字段、HTTP(S) 地址、时间顺序及未下架记录的 ID / URL 唯一性。定时上架必须在当前时间 2 分钟之后；立即上架使用当前时间覆盖原排期。
- 已确认排期仍显示“草稿 / 已确认定时上架”，到时转已上架；修改未变化的既有排期不会重新要求 2 分钟缓冲，修改排期则重新校验。
- 草稿可编辑、删除；已上架仅允许修改名称和下架时间；下架后只读，不允许编辑、删除或重新上架。
- 日志与课程管理合并：新增首列“操作项目”，共九列；其余分类、变更前后独立展开、字号及分页沿用共享方案。记录新增、删除、上下架、已上架字段修改；草稿编辑不写日志，定时动作操作人为“系统”。仅直播管理员不获取课程日志。

## 本地边界与待对接

- 存储独立使用 `gaip-learning-live-v12`，不迁移或覆盖 `gaip-learning-v11`。保存失败（如配额不足）不更新内存状态或写成功日志。
- 图片保存在本机浏览器存储；本轮限制 JPG / PNG / WebP、单张 2 MB，并建议 1500×640 图片。这是本地容量约束，不是生产上传接口标准；多张图片仍可能耗尽浏览器配额。
- 学习群组本轮按课程可见性处理：必选，“所有人”与具体群组互斥；只过滤 Banner 展示，不能代替目标直播平台鉴权。正式后端规则仍需联调确认。
- 完整链接在新标签页打开，并使用 noopener / noreferrer。直播 ID 到地址的转换规则未提供，因此 ID 类型点击仅提示“本地 Mock，尚未接入播放地址”，不伪造跳转。
- 本地定时器仅在学习中心运行或重新打开时补算；页面关闭期间没有后台调度，不声称服务器任务已接入。
- 权限为已有 Mock 角色判断，不是生产鉴权；不接真实上传、播放、消息推送或业务 API。
