2026-09-29：已将标签统一应用到表格和日志；用户后续确认六个基础色，精选另恢复原课程推荐金色，管理员使用身份色深底白字，四种职责和四个持牌地区使用暖灰底深灰字；[v1 方案](table-tag-color-mapping-v1.md) 保留原件，不覆盖历史。当前分类预览：[全局组件 → 表格标签](../components/index.html?component=table-tags)。

## 唯一维护入口

- `components/table/global-table-tag.js`：显式文案、业务分类和语义色；业务语义维持 `groups` 的23类、74个文案，预览按实际来源分组。原 67 个全部保留，补入学情的未学习/学习中/已完成、日志的上架/上架课节/下架/下架课节。下架操作归中性，删除操作归危险。
- `components/table/global-table-tag.css`：六套基础颜色、推荐金色、角色强调色和紧凑尺寸；视觉记录见 [标签台账](../design-changes/shared-table-tags.json)。调整配色只改这里，调整具体文案归属只改 `groups`。
- 业务和全局组件目录、真实弹窗预览共用这两个文件。频道入口通过 `shared/config/channels.js` 统一加载，跨频道 Hash 切换不另造实例。

## 基础语义色与推荐色

灰色用于中性分类和未启用/结束状态；蓝色用于规划方向、信息、进行中及修改操作；绿色用于有效、成功及新增；橙色用于待处理和提醒；红色用于失败和删除；身份色用于角色身份和持牌地区，区分管理员深底与职责、地区浅底。彩色浅底提高饱和度，管理员身份色深底采用白字，失败标签使用浅红底、红色文字与图标，具体参数只在共享CSS与视觉台账维护。

与v1相比，五个角色身份及四个持牌地区文案归identity，六种规划方向归info；精选归独立highlight推荐色，其他文案语义映射保留。当前数量为灰22、蓝17、绿15、橙5、红5、身份色9、推荐色1，共23类74文案。规划方向同列统一蓝色，用图标和文案区分具体方向。历史烟棕与低饱和方案保留于变更记录，v1快照不覆盖。

精选推荐色只用于推荐标记，与橙色待办/预警区分。共享标签工厂、旧表格适配、表格演示和颜色筛选使用同一highlight映射，原始五色v1存档保持不变。

## 深底强调样式

角色身份的“管理员”使用身份色深底白字，“人管、佣金、线索管理、线索跟进”以及“新加坡、美国、百慕大、香港”使用暖灰底深灰字；管理员深底复用身份文字变量 `--table-tag-identity-fg`。失败结果中的“失败、解析失败、创建失败”使用浅红底红字，实心失败SVG继承红色；“删除、删除成员”同样浅红底，以纯文字区分。

强度由groups的variant及逐文案variants显式定义，variantFor(text)完整匹配；当前管理员、草稿2个solid文案，其余均为soft。管理员保留identity语义，草稿保留neutral语义，仅强度变为深底白字，不额外增加色类。新工厂及旧表格适配同步颜色和强度，文本变化或离开范围时更新清理；深底图标通过currentColor反白。

## 接口与范围

`__GAIP_TABLE_TAG__.create(text, {tone, icon})` 返回 span，使用 `textContent`；原 `__GAIP_TABLE__.tag()` 委托同一工厂。已收录的文案优先使用统一映射；未收录文案默认 neutral，可显式传入 neutral/info/success/warning/danger/identity/highlight；highlight沿用原课程精选金色，不再映射为info。空白、`-`、`—` 是无底色占位，不参与分类。

旧表格以候选标签类与 `td` 双重限定，保留原 DOM、图标、事件与业务数据，添加 `data-gaip-table-tag` 语义标记，带图标标签另由组件接入内联 SVG。观察器响应异步行、翻页、文本和类变化；重复扫描不反复写入，不监听自己的标记，避免循环。退出表格或进入选择器后清理旧标记。可用 `data-gaip-table-tag-ignore` 显式排除子树。

范围包括组织、线索、活动、公告、财富值、课程/直播/学情及操作日志；卡片、详情徽章、筛选器、表单字段和选择器内选项不自动接管。新增普通文字不能仅凭文案变成标签；业务数据变化不改写历史日志。

## 预览中的来源与颜色说明

预览顶部展示六种基础色与推荐金色的分类逻辑、同源标签例子和深浅底规则（管理员与草稿深底白字，失败浅底红字红图标）。颜色按业务含义分配，不按频道分配；橙色是待办/预警，不泛指未开始。例子通过共享工厂渲染，独立于下方105个来源实例的搜索、颜色筛选与文案计数。

全局组件目录默认按“频道 → 页面/表格 → 字段与标签”展示，当前来源登记覆盖5个频道、18个表格场景、30处字段，共105个展示实例、74个不同文案。同文案按实际使用处重复，业务语义的23类及配色仍由共享工厂维护。搜索匹配频道、页面、字段或文案，并可叠加颜色筛选；无匹配的字段、页面及频道一起隐藏。颜色按钮统计唯一文案数，不把重复使用次数当文案种类。

来源唯一登记在 `components/table-tag-sources.js`，向预览提供有序locations和按文案查询的sources，业务页面不加载。登记依据当前渲染器、表头和本地数据；不扩展到表单选项、普通卡片徽章或表外状态。每个标签仍可悬停250ms或聚焦查看全部使用位置；指针可移入浮层阅读，Escape、外部点击、页面滚动、尺寸变化、筛选或切换组件关闭。

新增文案或使用位置时同步维护登记。DOM检查核对每个频道/页面/字段与对应文案、颜色及SVG同源，覆盖搜索与颜色组合筛选、空态和来源提示生命周期。来源提示仅用于目录；业务中仅被截断的自有标签增加全文提示和Tab焦点。浏览器视觉与窄屏实际布局尚未复验。

## 标签组与长文案（2026-09-30）

`__GAIP_TABLE_TAG__.createGroup(items, {label})` 返回共享组容器。items 接受文案字符串或 `{text, tone, icon}`；可选 label 是辅助阅读名称。现有容器可加 `data-gaip-table-tag-group`，组织成员的持牌身份与角色组也采用同一组样式，保留原节点。组内整枚换行、垂直居中，几何值见预览尺寸区和标签台账。

自有工厂为文字创建 `.gaip-table-tag__text`：单枚宽度上限为容器宽度，文字省略，图标保持原尺寸。实际溢出才开放全文提示与键盘焦点；悬停、点击或聚焦显示，Esc、移出、失焦、外部点击、滚动、隐藏、关闭所属dialog或移除节点时收起，解除溢出时恢复组件添加的Tab属性。原有tabindex和aria-describedby保留。来源目录已有完整文案及使用位置提示，不叠加第二层提示。

旧React标签不搬移或重包文字节点，因此全文省略增强限定共享工厂生成的标签；现有短文案和图标映射均保留。新增长文案调用共享工厂。预览使用真实共享表格渲染组织持牌、职责组合和独立长文案边界示例，示例不加入74个业务文案统计。

本轮标签行为与目录结构JSDOM检查通过；真实浏览器的文字裁切、换行和提示避让仍未验证，不能用模拟尺寸断言代替。用户明确保留六种规划方向线框与未学习空心圆。
