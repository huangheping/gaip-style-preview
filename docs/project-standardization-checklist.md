# 项目标准化验收清单 v1.0

依据 [[docs/project-standardization-spec|项目标准化规范]]；返回 [[knowledge/INDEX|知识总索引]]。这是当前实施的验收表。已勾选项有本轮证据；未勾选项表示仍待处理、未执行或不适用，具体见文末说明和 [[docs/standardization-status|实施状态]]。

## 验收记录格式

每次试点/迁移在目标项目 `outputs/standardization/<任务标识>/` 保存报告。记录实际 Git 根、起始提交、已有未提交变化摘要、频道、工具版本、浏览器版本、运行方式、检查日期、证据相对路径和剩余问题。项目内无 Git 提交时如实记录，不编造 SHA。

每项结果采用：通过 / 失败 / 未执行 / 不适用。不适用必须给理由；勾选仅表示有证据通过。静态、DOM、真实浏览器和人工审阅分别标注。报告中不得写入凭据或无关个人信息。

## A. 任务边界与基线

- [x] A01 已确认实际项目根目录、操作模式（原项目重构或独立抽离）和目标路径。
- [x] A02 已登记本任务范围、原有修改及排除素材；没有覆盖其他任务的文件。
- [ ] A03 抽离时全部产物在指定目标内，来源项目无新增、修改、删除及工具缓存写入；用前后差异证明。
- [ ] A04 保存迁移前的入口、关键交互、依赖和可获得的视觉依据；缺失证据明确标注。

## B. 频道目录和资源

- [x] B01 每个受验频道有可维护 HTML、独立 CSS 和 JS，不以空壳或未使用文件满足数量要求。
- [x] B02 图片、图标及其他频道私有资产位于本频道目录；共享/组件资产有明确归属。
- [ ] B03 HTML、CSS、JS 中资源路径均可解析；大小写和 CSS 相对路径正确，无跨频道私有依赖。
- [x] B04 交付不依赖源项目绝对路径、外部项目软链接或在线下载素材。
- [x] B05 旧路径引用已核对；待移除文件有引用证据和恢复办法，排除候选未混入交付。
- [ ] B06 单频道独立包在源目录不可用时仍能打开，组件与公共资源已随包提供；不要求此交付时记录不适用。

## C. HTML/CSS/JS 分离与语义

- [x] C01 源 HTML 无 `style` 属性和 `<style>`；link 加载独立 CSS，脚本外置。
- [x] C02 未通过 JS 注入静态样式或大段静态 DOM 来规避文件分离；动态渲染与布局需求有说明。
- [ ] C03 导航、按钮、表单、表格使用适当原生元素，布局容器结构清晰，类名稳定。
- [ ] C04 无内联事件；CSS 作用域、JS 挂载/销毁和重复进入行为明确。
- [ ] C05 检查生成产物与实际 DOM，第三方或框架生成的内联样式单独列明；未满足严格要求不标全通过。
- [ ] C06 键盘可操作、焦点可见、表单标签和图标名称有效；错误与空状态可理解。
- [x] C07 本轮审计的自有脚本固定样式已迁出；AST 防回退检查、动态值精确登记和新项目模板检查已验证。343 份自有固定结构片段也已迁入 HTML 源；C05 中的第三方运行时样式例外仍保留，见 [[docs/js-style-separation]] 和 [[docs/markup-source-completion-20260925]]。

## D. 组件库

- [x] D01 组件库有独立目录与唯一源码；组件自身资产随组件管理。
- [x] D02 展示页直接调用真实组件，不维护另一套 DOM/CSS；适用状态可预览。
- [ ] D03 文档说明组件输入、事件、依赖与销毁；组件不依赖具体频道。
- [x] D04 修改共享组件后已检查实际消费者，未出现重复监听或遗留观察器。
- [ ] D05 GAIP 弹窗登记、共享确认、遮罩/定位均保留，关闭后底层可点击，再次打开正常。

## E. 运行行为（真实浏览器）

- [x] E01 以既有 `file://` 方式直开频道，图片、图标、字体、CSS 与 JS 正常，未要求新增服务器才能预览。
- [x] E02 从另一个入口切入该频道，看到同一版本；主文档没有整页重载。
- [x] E03 当前 Hash 优先，刷新保留频道/子视图；前进后退行为合理。
- [ ] E04 导航父项仅开合，叶子/二级项才导航；当前态、键盘和滚动层符合原契约。
- [ ] E05 相关业务操作、Mock 状态和共享弹窗正常，无意外真实接口请求。
- [x] E06 控制台/资源错误已检查；视频、上传等未接真实服务的部分如实说明。
- [ ] E07 桌面与窄屏布局无意外回退，视觉修改已按原流程记录；纯迁移未伪造样式差异。

- [x] F05 知识笔记解释需求和原因，源码事实不复制成多份手工台账；视觉参数只维护既有台账。

## H. 自动检查、同步与未来模板

- [x] H01 本地检查可发现缺文件、内嵌样式、坏路径、跨频道私有依赖和坏知识链接；有真实失败样例验证，不仅输出“通过”。
- [x] H02 按改动范围完成现有静态/DOM 检查，并与 E 节真实浏览器结果分开记录。
- [x] H03 本地 GitHub 同步规则可从 AGENTS 和知识索引到达；同步流程只有一个维护入口，具体排除清单不重复，整理规则不被当作推送授权。新增远程工作流不属于本项要求。
- [x] H04 提交范围不包含密钥、本机路径配置、依赖目录和用户排除素材；push/发布在实际授权范围内。
- [x] H05 新项目模板携带规范版本、规则入口、频道/组件骨架、知识索引和可运行检查命令。
- [x] H06 从模板建立新项目后，断开原模板路径仍能工作；AOCI 认知和 baseline 属于新项目而非复制旧项目。
- [ ] H07 新 Codex 任务能找到本项目 AGENTS 和适用 Skill；未验证的自动发现不宣称生效。
- [x] H08 文档、生成器、检查工具和项目规则中路径约定一致；迁移完成后不再保留两套手工事实源。

## 退出条件

单频道试点至少完成适用的 A–F 项；AOCI 接入完成须满足 G 项；“后续项目严格标准化”须进一步完成 H 项。任何未执行项保留原因、影响和下一步，不将试点成功外推为全项目成功。
