# Agent / Skill 官方文档审计与优化

本轮审计文稿正式仓库 `/Users/hhp/Documents/GAIP项目集/样式优化html` 的根指令、两个项目技能、发现入口、维护流程和新项目生成规则。实际对话 cwd 仍在桌面测试副本；本轮所有命令显式指定正式根，没有修改桌面或全局 Codex 配置。网站 `components/ai-agent/`、原站 `web/` 和现有业务改动不在本轮修改范围。

结论：现有分层和两个技能的数量合理，主要问题是重复读取、触发范围与任务路由不完全一致、验收声明容易混用，以及新项目规则仍用长内联字符串维护。本轮落实以下调整，没有强制换模型、创建子代理或安装新的项目技能。

以下页面均于 2026-09-30 实际查询并打开；旧 9 月 7 日审计保留为历史，不作为当前实现或权限证据。

| [AGENTS.md 发现与分层](https://learn.chatgpt.com/docs/agent-configuration/agents-md) | 指令按项目根到工作目录发现，override 优先；运行开始建立指令链，默认总预算 32 KiB。常驻规则保留稳定约束。 |

上述是官方机制与建议；本项目的 HTML/CSS/JS 分离、Hash 不刷新、目录归属、来源只读、视觉台账、禁止推送和 AOCI 协议来自用户与项目契约。官方没有为 GAIP 强制这些实现。AOCI 机器区块不按通用“精简提示词”建议改写。
