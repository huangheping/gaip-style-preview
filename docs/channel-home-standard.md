# 主导航频道首页规范 v1

## 1. 规范目标

本规范用于统一主导航频道首页的代码结构、视觉基础和交互规则。统一的是产品语言和基础
体验，不要求不同业务频道使用完全相同的内容布局。

## 2. 规范层级

规范按以下顺序生效：

1. 应用框架：全局顶栏、主导航侧栏、主内容区、AI 助手入口。
2. 设计变量：字体、字号、颜色、间距、圆角、边框、控件高度和滚动条。
3. 页面类型：看板型、主从分栏型、列表检索型、引导学习型。
4. 频道区域：频道页头、主视觉区、频道导航、操作区、筛选区、指标区和内容区。
5. 业务模块：卡片、表格、课程、活动、客户详情等频道专属内容。

上层规则必须统一；下层规则可以在不破坏上层规则的前提下保留业务差异。

## 3. 应用框架

| 项目 | 规范值 | 规则 |
| --- | --- | --- |
| 全局顶栏高度 | `56px` | 所有登录后频道一致 |
| 主导航侧栏宽度 | `212px` | 展开状态一致 |
| 主内容区最小宽度 | `0` | 防止 Flex 子项产生横向溢出 |
| 页面基础字号 | `14px` | 继续使用全局字号阶梯 |
| 全局字体 | HarmonyOS Sans SC Regular | 只加载真实 `400` |
| 主品牌色 | `#025B52` | 主要按钮、选中态和重点文字 |
| AI 助手入口 | 全局固定 | 不由频道页面重复创建 |

应用框架统一使用现有稳定名称：

- `app-shell`
- `app-header`
- `app-sidebar`
- `primary-nav`
- `app-main`
- `ai-assistant-entry`

### 全局面包屑

- 工作台首页只显示 `工作台总览`，不重复显示“首页 / 工作台总览”。
- 其他频道首页显示 `工作台总览 / 当前频道`。
- 频道详情页显示 `工作台总览 / 当前频道 / 当前详情`。
- 根节点和中间节点可返回，当前节点使用 `aria-current="page"` 且不可点击。
- 面包屑名称、路由和频道标识必须来自 `shared/config/channels.js`。
- 所有频道共用一个面包屑控制器，频道功能脚本不得直接重写整段面包屑 HTML。

## 4. 公共设计变量

### 颜色

| 变量 | 数值 | 用途 |
| --- | --- | --- |
| `--gaip-color-brand` | `#025B52` | 主按钮、选中态、主要链接 |
| `--gaip-color-accent` | `#24D4C9` | 少量强调线、状态提示 |
| `--gaip-color-text` | `#2F3640` | 正文和标题 |
| `--gaip-color-text-secondary` | `rgba(47,54,64,.65)` | 说明、时间和次要信息 |
| `--gaip-color-border` | `rgba(47,54,64,.12)` | 卡片、输入框和分隔线 |
| `--gaip-color-canvas` | `#FAFAFA` | 常规频道页面背景 |
| `--gaip-color-surface` | `#FFFFFF` | 卡片、表格和固定工具栏 |
| `--gaip-color-surface-subtle` | `#F5F4F2` | 次级内容背景 |

### 间距

只使用以下基础间距：

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48px`

| 场景 | 规范值 |
| --- | --- |
| 页面左右边距 | `24px` |
| 主要区块间距 | `24px` |
| 卡片内部间距 | `24px` |
| 表单项和紧凑卡片间距 | `16px` |
| 图标与文字间距 | `8px` 或 `12px` |

`6px` 和 `10px` 只用于组件内部微调，不作为页面级间距。

### 圆角

| 场景 | 规范值 |
| --- | --- |
| 输入框、按钮 | `4px` |
| 卡片、表格容器、筛选容器 | `8px` |
| 强调型大卡片 | `12px` |
| 标签、胶囊按钮 | `999px` |

不再为相同组件分别使用 `3 / 4 / 6 / 8 / 10 / 12px`。

### 控件高度

| 级别 | 高度 | 用途 |
| --- | --- | --- |
| 紧凑 | `36px` | 筛选标签、小型选择器 |
| 常规 | `40px` | 普通按钮、搜索框、选择器 |
| 强调 | `48px` | 页头主要操作、重要搜索入口 |

同一操作区内的按钮、搜索框和选择器必须保持同高。

## 5. 频道首页区域

### 必需区域

每个频道首页必须具有：

- `channel-page`
- `page-content`，或明确的 `content-sidebar + content-main`

### 可选区域

根据业务使用：

- `page-header`
- `page-hero`
- `page-nav`
- `section-nav`
- `page-actions`
- `filter-toolbar`
- `metric-overview`
- `content-sidebar`
- `content-main`

`page-header` 和 `page-hero` 可以同时存在，也可以由主视觉区承载标题和操作；不要求为了
形式统一而额外增加空页头。

## 6. 四类页面骨架

### A. 看板型

适用：工作台、活动中心、线索中心。

- 页面可随文档纵向滚动。
- 主视觉、指标概览和页面内容按顺序排列。
- 页面内容左右边距和模块间距统一为 `24px`。
- 指标卡片高度、数字字号可以按业务保留差异。

### B. 主从分栏型

适用：客户中心、方案中心。

- 页面高度为 `calc(100vh - 56px)`。
- 页面自身不产生第二条纵向滚动条。
- 内容侧栏固定宽度，内容主体使用剩余空间。
- 侧栏与主体可以分别滚动，但应避免再出现第三层滚动。

### C. 列表检索型

适用：保单列表、产品中心。

- 页头/频道导航和筛选区固定在结果列表上方。
- 结果区域承担主要纵向滚动。
- 筛选控件同高，筛选区左右边距统一为 `24px`。
- 卡片列表和表格都使用 `24px` 内容边距和 `24px` 主间距。

### D. 引导学习型

适用：薄荷入职引导、学习中心。

- 页头和频道/章节导航固定。
- 学习内容区承担主要纵向滚动。
- 课程卡片或章节内容允许使用专属背景和图片比例。
- 返回、上一节、下一节等流程操作必须保持位置稳定。

## 7. 滚动规则

1. 一个频道首页只设一个主要纵向滚动容器。
2. 横向滚动只允许出现在无法合理折行的表格或数据区域。
3. 页面滚动条统一使用全局灰色样式，频道 CSS 不再定义滚动条颜色和宽度。
4. 固定页头或筛选区时，应在其下方的内容容器设置滚动，不在多个祖先上重复设置。
5. 不通过隐藏滚动条来掩盖内容溢出。

## 8. 组件规则

### 卡片

- 普通卡片使用白色背景、`8px` 圆角和统一边框。
- 卡片内部默认 `24px`。
- 同一列表内卡片高度可以由内容决定，但列间距必须一致。

### 筛选工具栏

- 筛选项按“主要条件 → 次要条件 → 搜索 → 操作”排列。
- “清空筛选”位于筛选项末尾，不作为主要按钮。
- 筛选项超过一行时按 `12px` 行间距换行。

### 页面操作

- 一个操作区只有一个主要操作。
- 新建、生成、报名等使用主品牌色。
- 导出、下载、查看等使用次要或描边按钮。

### 空、加载和错误状态

每个频道首页至少提供：

- 加载状态
- 无数据状态
- 筛选无结果状态
- 接口失败状态
- 无权限状态

空状态必须说明当前没有什么，以及用户下一步能做什么。

## 9. 频道与路由规则

频道名称、频道标识、Hash 路由、HTML 入口文件和导航图标必须来自同一份频道注册表。

| 字段 | 示例 |
| --- | --- |
| `key` | `workspace` |
| `label` | `工作台总览` |
| `route` | `/workspace` |
| `entry` | `工作台.html` |
| `icon` | `workspace` |
| `type` | `dashboard` |

HTML 文件名可以因离线预览保留中文，但代码内部统一使用英文 `key`。

## 10. 文件组织

```text
shared/
  config/
    channels.js
  scripts/
    channel-entry-navigation.js
    channel-regions.js
    learning-nav.js
  styles/
    global-font.css
    channel-foundation.css
features/
  <channel>/
    <channel>.css
    <channel>.js
```

- `web/` 为原构建产物，不作为新规范的主要修改位置。
- 全局变量和跨频道规则放在 `shared/`。
- 频道专属规则放在 `features/<channel>/`。
- 不把新业务样式继续追加到无关频道文件。

## 11. 落地顺序

1. 建立唯一频道注册表。
2. 建立公共设计变量和基础结构样式。
3. 先处理工作台、产品中心、学习中心三类代表页面。
4. 将验证后的规则扩展到同类频道。
5. 每次修改同步更新本规范和全局修改记录。

## 12. 验收清单

- 控件类改动使用代码、DOM、状态、路由和可访问性属性验收，不以截图审查作为验收方式。
- 主导航切换无刷新。
- 地址栏入口文件始终位于当前 `样式优化html/`。
- 顶栏高度和侧栏宽度一致。
- 页面区域使用稳定名称。
- 页面级边距和主要区块间距符合规范。
- 同一操作区控件同高。
- 页面只有一个主要纵向滚动容器。
- 默认、加载、空、错误和无权限状态可识别。
- 不依赖哈希类名编写新的公共样式。
- 频道专属视觉没有被全局规则误伤。
