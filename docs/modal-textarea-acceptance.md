## 唯一实现

- `shared/scripts/global-modal.js`：识别弹窗及原字段、外壳、计数节点。
- `shared/styles/global-modal.css`：输入外框、正文、独立计数行及外框手柄视觉；具体参数只维护于 `design-changes/modal-interiors.json`。
- `shared/scripts/modal-controls.js`：外框手柄控制原textarea高度，处理禁用、键盘、拖动和清理。
- 预览继续调用来源，不能为了通过预览验收复制字段或另写样式。

## 固定契约

1. 正文滚动视口与计数行分离；禁止恢复绝对定位计数覆盖正文的实现。
2. 有手动缩放功能时，只有一个外框手柄；内部原生手柄由共享样式抑制。自动增高字段不新增手柄。
3. 字段值、字数统计、长度限制、自动高度、校验及保存由原业务负责。接入器不搬动React管理的字段与计数节点。
4. 单字段或fieldset禁用、只读均不能拖动；关闭、卸载、失焦、pointercancel及退出共享范围时停止拖动/清理增强。
5. 字号、颜色、外框和计数间距只改共享源与同一参数记录。不能为了修一个角落反向破坏上述规则。

### 新本地来源的明确接入

在真实业务工厂的现有结构上标记，不在预览里创建副本：

```html
<span data-gaip-modal-part="counted-textarea">
  <textarea rows="5" maxlength="500" aria-label="说明"></textarea>
  <span data-gaip-modal-part="count">0 / 500</span>
</span>
```

挂载真实弹窗后调用 `__GAIP_MODAL_COMPONENT__.adoptForm(dialog)`；现有观察器负责后续控件接入。业务自己更新计数内容。自动增高字段保持自身`resize:none`策略；不要用内联`resize:...!important`抵消共享规则。新弹窗照常使用`@gaip-modal`登记。

没有计数的手动缩放字段，外壳声明`data-gaip-modal-part="resizable-textarea"`，内部只保留原textarea，不新增计数节点。07活动报名备注采用此方式；手柄来自同一个控制器与CSS，不能将“无计数”当成继续使用独立原生手柄的理由。

## 回归与验收边界

- `npm run test:modal-source`：读取原客户分包，在内存暴露原组件；使用项目自带React/Ant，隔离应用启动与后端模型。检查空值、短文、上限文本的真实onChange/计数、原节点、手柄计算、源关闭回调、保存中状态和卸载重开。不改`web/`，不加载弹窗预览HTML，也不发网络请求。
- `npm run test:modal-forms`：包含上项，并覆盖共享状态、字段排除、fieldset禁用、明确接入标记、观察器和生命周期。
- DOM测试中的尺寸是明确模拟值，不能证明像素间距、裁切、鼠标命中、原生顶层或滚动条实际位置。

**第1步浏览器视觉验收仍未完成**：本轮没有浏览器控制/截图工具。应直接在23、24上述来源入口，检查短文/上限文本、顶部/中间/底部滚动、拖动前后、关闭重开，以及较矮视口；同时确认手柄贴外框、计数不穿字、底栏不被挤出、按钮右边与内容对齐。不得把工具缺口解释成“引用弹窗必然无法验收”。
