需要优先解决的混用

业务类型与风险状态分开
“保险财富值”在导入工作台是橙色，在我的财富值是蓝色。建议普通类型统一灰色；橙色保留给待处理和预警。

正常结束不等于失败
已下架、已关闭、活动结束归灰色。解析失败、创建失败归红色；“报名结束”也不再使用警告橙。

同一操作跨模块一致
新增用绿，编辑/设置用蓝，查看/导出用灰，删除用红。组织日志目前所有操作都为黄色，共享日志的查看则为紫色。

角色靠文字辨识
管理员、人管、佣金、线索管理、线索跟进统一蓝色；地区与内部/外部关系归灰色。持牌用绿色，不持牌用灰色。
