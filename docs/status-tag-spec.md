# 全局状态标签规范

全局状态标签用于卡片、详情摘要等非表格场景，以短文案说明对象当前状态。它是只读信息，不承担筛选、计数或操作。

## 规格

- 高度：24px。
- 字号与行高：12px / 18px。
- 左右内边距：10px。
- 圆角：12px胶囊形。
- 默认无图标、无边框、无 hover、无选中态。
- 文案保持单行，并明确表达状态；不能只靠颜色传达含义。

## 语义

- `success`：已完成或当前有效。当前文案为“已归属”。
- `warning`：仍需用户后续处理。当前文案为“待确认客户归属”。

颜色值由 `components/status-tag/global-status-tag.css` 唯一维护。表格标签继续使用20px紧凑规格，不因本组件接入而改变。

## 接入边界

使用 `<span data-gaip-status-tag="success|warning">文案</span>` 显式接入；组件不自动扫描页面，也不按中文文案猜测语义。

客户姓名、方案ID、顶部状态筛选、左侧数量和“确认归属”等操作按钮不属于状态标签。动态更新状态时由业务重新渲染文案与语义属性；静态标签本身不增加焦点或ARIA角色。
