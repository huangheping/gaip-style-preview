## 第一轮：组件与重复加载

- AI 助手原来的基础、动画、改版和入口 4 份 CSS，按原顺序合为 `components/ai-agent/AI Agent.css`，减少 3 个文件。保持同一目录，素材相对路径、覆盖次序及视觉参数不变；所有正式入口已同步。未发布登录视频候选只同步依赖引用，继续排除提交。
- AI 原版备份（2 个 CSS、1 个 JS 和 12 个素材）与配置中心未加载旧快照（1 个 CSS）移入 [[docs/archive/历史源码/README|历史源码归档]]。每个文件保留原始字节、原路径与 SHA-256。
- `channel-features.js` 按浏览器解析后的完整 URL 查重，保留查询版本号和脚本依赖顺序。日志导出脚本在加载器之前声明，避免尚未解析时被再插入。修复共享弹窗 CSS/JS、日期选择器 CSS/JS、日志 XLSX 脚本共 5 项重复插入。
- 单个正式频道入口少 3 个 AI 样式链接，再少 2 个重复 CSS 和 3 个重复 JS 标签。标签减少不等同于同等网络传输减少，浏览器还存在缓存；不声称 JS 实现代码减少。

## 为什么仍然保留多个文件

学习中心的课程数据、课程管理、直播和页面挂载各有职责。课程/直播领域承担存储迁移、权限、状态校验和日志，并非只有示例数组，因此继续单独维护和测试。AI 的 Mock 和入口动效 JS 同样保持分工。

共享组件按表格、筛选、日期、组织树等功能复用，不把它们复制到每个频道；131 字节的海报嵌入脚本在正文解析前设置模式，主脚本在正文后绑定元素，保留时序。

弹窗遮罩、主体、定位 CSS 继续独立。它们服务不同弹窗类型，现有入口在主体与定位之间加载表单和日期样式；直接拼接会改变覆盖顺序。这轮保留该契约。

2026-09-25：9 组频道 legacy 已替换为 page.js/page.css，web 仍是只读基线；共享目录新增 html-view.js 和 page-vendor.js 两个必要运行文件。HTML 模板与生成的 JS 注册文件分别承担维护源和 `file://` 加载产物，也不属于无用重复。

“频道独立 HTML/CSS/JS”指所有权明确、结构/样式/脚本分离，不强制每种只留一个文件。未被一次首页访问加载不足以证明无用，弹窗、管理页和分包可能延迟加载。
