# 剩余标准化审计

> 这是迁移前盘点。上述结构已在后续迁移到 HTML，当前维护入口与验收见 [[docs/markup-source-completion-20260925]]。

本轮基准为 ab3b711，范围是文稿项目的 channels、components、shared、app。原站 web、历史归档、依赖、输出、排除候选分别处理，不作为删除目标。关联 [[docs/source-file-inventory|文件数量]]、[[docs/js-style-separation|样式检查]]、[[docs/html-source-restoration-20260925|9 组旧页面]]。

## 样式检查与本次修复

检查 87 份自有 JS（包含本地未提交测试入口），70 个动态写入有精确表达式登记，3 个第三方/框架文件按哈希锁定。未发现新的未登记固定样式。人工核对了几何、进度、表格列宽等边界；这不等于能证明任意动态执行的 JS 均不可能产生 CSS。

修复检查器的实际缺口：原 HTML querySelectorAll 不进入 template.content。现在递归检查 HTML 模板，包括嵌套模板的内联 CSS、脚本、事件和资源路径；SVG 中同名占位元素按普通子节点处理，避免误判为 HTML 模板。JS 检查新增直接 jsx/jsxs 调用创建 style、setAttributeNS 写 style、静态字符串拼接隐藏 style 标签/属性的检测。失败样例与有效模板路径均有回归。网站业务和视觉参数未改变。

## 还在 JS 中的结构

AST 清单定位的是字符串片段，不是实际 DOM 数量；自动扫描不证明每处都可直接抽成模板。排除了明确生成缓存，人工区分以下情况：

| 来源 | 已确认边界 | 后续维护方式 |
| --- | --- | --- |
| 学习中心 learning-app.js / learning-live.js | 课程、学情、编辑表单和直播表单含静态结构与动态行；首页只有骨架先模板化 | 按一个业务表单或页面迁移，并核验存储、上传、拖拽、权限和关闭行为 |
| 财富值 wealth-center.js | 工作台、记录、明细和弹层由 render 系列函数生成 | 结构写入频道模板，业务数据与事件保留；分别验证三个路由和导入流程 |
| 配置 config-center.js / announcement-management-view.js | 现有模板之外仍有组织调整、导入和公告结构 | 不宣称 templates 已覆盖全部；按真实组件和对应 DOM 测试迁移 |
| 方案、活动、工作台适配脚本 | 原页面 HTML 已恢复，但本地新增适配还含结构字符串 | 保留适配事件和源弹窗身份，逐处合并到所属频道模板 |
| 组件目录、弹窗预览、AI Mock、操作日志、重要提示 | 目录卡片和组件/业务弹层仍由 JS 生成 | 结构按真实所有者拆出，展示与业务继续共用一份实现 |
| shared/scripts/local-preview.js 的 detailHtml | 产品详情的 Mock 富文本响应，目前无内联 CSS | 应归产品 HTML 模板并保留响应格式；不能将整个 Mock 删除 |
| operation-log-xlsx.js | Excel 导出的 XML，包括 styles.xml | 这是导出文件格式，不能当作网页 CSS 或无用 DOM 删除 |
| 表格、日期、筛选、树、轮播等组件 | createElement、数据循环、图标和状态渲染 | 动态节点不等于重复文件；固定骨架与数据渲染分开审查 |

因此“9 组旧编译页面恢复完成”只覆盖该轮页面视图，不能扩展成“所有共享组件和本地适配都已没有 JS 静态结构”。本轮完成盘点与检查修复，没有把这些剩余项标成已迁移。

## 文件数量与合并结论

正式运行目录已跟踪源文件为 48 CSS / 88 JS，无完全相同文件。源模板、生成缓存、入口、业务、数据领域与第三方运行时各有职责；所有文件均有字面引用证据，尚无可直接删除的候选。配置/学习/财富值/资讯四个 README 已纠正“桌面副本”字样，学习和配置的模板覆盖范围已写明。

没有改动站点运行源码，不需要用再次全站截图代替本轮检查器验收。检查范围为标准检查、真实失败样例、生成器继承检查、知识链接/属性及 Git diff。AOCI 官方开发分支验证另见 [[docs/aoci-integration-blocker]]。
