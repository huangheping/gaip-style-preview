# GAIP 频道维护

目标：用户从任意根 HTML 打开或切换频道，都得到同一份本地源码，保留 Hash 无刷新体验。

先确认当前目录属于包含 `shared/config/channels.js` 的 GAIP 仓库。以下路径相对本 Skill 目录；命令在仓库根运行。

## 定位唯一源码

- 读对应频道笔记和 [频道资源加载](../../../knowledge/公共模块/频道资源加载.md)，用注册表确定 `features/` 下的真实 CSS/JS。用户提到“方案中心.html”不意味着改版应写进 HTML。
- 涉及导航、默认 Hash 或刷新时，读 [主导航契约](../../../knowledge/公共模块/主导航与Hash路由.md)。保留父项纯开合、叶子导航、当前 Hash 优先及 file 入口默认值规则。
- 核对目标文件现有 diff 与资源引用，再改所属源码。新增资源登记一次；入口引用或共享缓存版本变化时找到所有实际消费者，包括组件预览，不硬编码入口数量。
- 从用户给定的入口和 Hash 查出故障：区分资源未加载、虚拟频道状态未清理、点击被遮挡、事件拦截。仅有静态猜测时不要声称已现场复现。

## 实现与验收

复用项目现有样式、图标和 Mock，保持修改范围。不要把“预加载慢”直接处理成删掉跨频道注册或改用整页跳转。

按照 [维护流程](../../../docs/maintenance-workflow.md) 的验证矩阵执行：代码或入口改变运行 `./scripts/verify-local-navigation.sh`；主导航行为改变再跑 `node scripts/test-expandable-main-nav.cjs`，并验证两条不同入口的切换路径。刷新问题还应核对当前 Hash 保留。

完成后记录本任务的源码、引用、自动检查和现场验证状态，更新当前变更与项目状态。不能自动访问用户的 file 页面时，给出实际限制和可操作的验收路径；不声称 JSDOM 等于浏览器点击验证。
