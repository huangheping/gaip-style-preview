# GAIP 频道维护

从用户指定入口和 Hash 定位，让不同入口复用同一实现并保持无刷新导航。遵守目标仓库 AGENTS 的范围、抽离例外及交付规则；诊断请求不自动授权改代码。

以下链接相对本技能目录，命令在已确认的 Git 根运行。确认该根含 `shared/config/channels.js`；核对浏览器地址与实际修改文件属于哪份项目，不以其他标签页推断。

## 定位与修改

- 用注册表找所属频道 CSS/JS、挂载/卸载入口和实际依赖；资源或跨入口问题查 [频道资源加载](../../../knowledge/公共模块/频道资源加载.md)。Hash、默认入口或导航问题查 [主导航契约](../../../knowledge/公共模块/主导航与Hash路由.md)。只读本次相关笔记及源码。
- 区分资源未加载、旧缓存、规则被覆盖、虚拟频道状态残留和事件/遮挡问题；记录直接证据，未现场复现则写明。样式不生效需检查实际加载文件、选择器状态与层叠；“固定”需检查定位及滚动容器，不能据此改无关宽度。
- 频道结构改 HTML 模板，外观改所属 CSS，行为改 JS；保留 Umi/React 节点和 Mock。根登录、中文目录及生成缓存不手改，所有消费者包括组件预览复用同一资源版本，不硬编码入口数量。
- 入口/频道登记变化运行 `npm run build:entries`；HTML 模板变化运行 `npm run build:templates`。不能通过整页跳转或删除跨频道预加载修复旧页面。

## 验收与输出

按 [维护矩阵](../../../docs/maintenance-workflow.md) 执行相关检查：浏览器代码/入口变化保留 `./scripts/verify-local-navigation.sh`；主导航行为改动再运行 `node scripts/test-expandable-main-nav.cjs`。允许的现场验证覆盖两个不同入口、当前 Hash 刷新及切换不重载；父项只开合，叶子才导航。

输出实际仓库、成因、所属源与消费者、检查证据及未验证项。DOM 与真实布局/点击分列；工具受限记录当前拒绝与缺口，不绕过，也不把旧验收当本次通过。记录与 AOCI 收尾按根规则执行，不在技能内另建流程。
