# 频道资源加载

## 职责

频道专属实现位于 `channels/<频道>/`，并通过 `shared/config/channels.js` 的 `assets.styles` 和 `assets.scripts` 登记。`shared/scripts/channel-features.js` 从任何入口预加载已登记资源。

## 为什么需要它

配置中心另外登记源 DOM 模板及原站组件/页面样式；模板先于交互脚本加载，CSS 限定在配置中心作用域。配置中心运行时样式已分为 `ant-source.css` 组件基线、`announcement-management.css?v=20260903-9` 公告管理独立样式、`config-center-content.css?v=20260904-34` 组织架构主体内容和 `config-center.css?v=20260902-8` 主导航/顶部/挂载外壳，交互 JS 为 `20260904-44`；未拆分的 `docs/archive/历史源码/配置中心/organization-source.css` 仅作为原站快照保留，不再登记加载。全部正式频道入口的频道注册表缓存为 `20260904-67`，源模板为 `20260902-1`。财富值资源为 `20260902-2`、全局框架为 `20260904-4`、区域标记脚本为 `20260904-3`。

弹窗预览的正式频道触发模式由频道入口继续加载 `shared/scripts/local-preview.js?v=20260902-7`；仅当 Hash 查询参数包含 `gaip-popup-preview` 时，才动态加载 `popup-preview-bridge.js?v=20260902-7` 并点击当前频道的真实业务入口。普通页面和正常 Hash 导航不启用该桥接脚本。父预览页初始不创建频道 iframe；只有对应卡片进入可见区域或用户点击“立即加载”后才创建，并继续以最多 3 个并发启动。预览桥成功打开真实弹窗后，会删除弹窗所在分支以外的频道页面 DOM，只保留原弹窗、遮罩、Portal 与必要父级；父预览页同时显示逐项加载失败原因。桥接入口最长等待 45 秒，并用真实内容节点区分客户卡片、产品卡片与同类名骨架屏。AI Agent 的对话名称弹窗从工作台真实入口打开，不再加载无关的 `/agents/riskAccess` 页面；入职完成弹窗从当前真实进度逐步点击“下一步”直到“完成”，每一步等待 React 提交后再继续，不依赖固定初始进度。

Hash SPA 切换不会重新读取目标 HTML。若专属 CSS/JS 只写在某个 HTML，其他入口切换到该频道时会出现旧页面或丢失改版。

## 不变量

- `assets.bootstrapScripts` 登记必须在 Umi 模块首次求值前安装的源模块适配器。正式频道入口以普通解析脚本加载 `local-preview.js`，它按注册表同步插入这些脚本；不得改为 defer/async 或移动至 Umi 后。当前消费者包括薄荷入职引导第 2 章，以及薄荷/产品中心共用的专家库（相同URL仅加载一次）；普通 CSS/JS 仍由 `channel-features.js` 加载。

- 一个频道改版只有一份源码。
- 频道 HTML 的活跃入口保持薄壳，可包含惰性 template 页面结构源；根 index.html 为登录入口；app/project-index/index.html 提供中文项目目录。
- `web/` 不承载本地改版。
- 登记后验证直接打开与跨频道切换两条路径。

## 2026-09-30 本地图标缓存
