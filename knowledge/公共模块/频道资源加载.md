# 频道资源加载

## 职责

频道专属实现位于 `features/<频道>/`，并通过 `shared/config/channels.js` 的 `assets.styles` 和 `assets.scripts` 登记。`shared/scripts/channel-features.js` 从任何入口预加载已登记资源。

## 为什么需要它

Hash SPA 切换不会重新读取目标 HTML。若专属 CSS/JS 只写在某个 HTML，其他入口切换到该频道时会出现旧页面或丢失改版。

## 不变量

- 一个频道改版只有一份源码。
- 根 HTML 保持薄壳。
- `web/` 不承载本地改版。
- 登记后验证直接打开与跨频道切换两条路径。
