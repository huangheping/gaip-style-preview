# 频道资源加载

## 职责

频道专属实现位于 `features/<频道>/`，并通过 `shared/config/channels.js` 的 `assets.styles` 和 `assets.scripts` 登记。`shared/scripts/channel-features.js` 从任何入口预加载已登记资源。

## 为什么需要它

配置中心另外登记源 DOM 模板及原站组件/页面样式；模板先于交互脚本加载，CSS 限定在配置中心作用域。配置中心运行时样式已分为 `ant-source.css` 组件基线、`config-center-content.css?v=20260902-21` 主体内容和 `config-center.css?v=20260902-8` 主导航/顶部/挂载外壳，交互 JS 为 `20260902-24`；未拆分的 `organization-source.css` 仅作为原站快照保留，不再登记加载。全部正式根入口的频道注册表缓存为 `20260902-34`，源模板为 `20260902-1`。财富值资源为 `20260902-2`、全局框架为 `20260901-7`、区域标记脚本为 `20260901-1`。

弹窗预览的正式频道触发模式由根入口继续加载 `shared/scripts/local-preview.js?v=20260902-7`；仅当 Hash 查询参数包含 `gaip-popup-preview` 时，才动态加载 `popup-preview-bridge.js?v=20260902-7` 并点击当前频道的真实业务入口。普通页面和正常 Hash 导航不启用该桥接脚本。父预览页初始不创建频道 iframe；只有对应卡片进入可见区域或用户点击“立即加载”后才创建，并继续以最多 3 个并发启动。预览桥成功打开真实弹窗后，会删除弹窗所在分支以外的频道页面 DOM，只保留原弹窗、遮罩、Portal 与必要父级；父预览页同时显示逐项加载失败原因。桥接入口最长等待 45 秒，并用真实内容节点区分客户卡片、产品卡片与同类名骨架屏。AI Agent 的对话名称弹窗从工作台真实入口打开，不再加载无关的 `/agents/riskAccess` 页面；入职完成弹窗从当前真实进度逐步点击“下一步”直到“完成”，每一步等待 React 提交后再继续，不依赖固定初始进度。

Hash SPA 切换不会重新读取目标 HTML。若专属 CSS/JS 只写在某个 HTML，其他入口切换到该频道时会出现旧页面或丢失改版。

## 不变量

- 一个频道改版只有一份源码。
- 根 HTML 保持薄壳。
- `web/` 不承载本地改版。
- 登记后验证直接打开与跨频道切换两条路径。
