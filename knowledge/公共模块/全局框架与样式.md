## 修改规则

影响多个频道的规则放在共享层；频道专属视觉不放入全局 CSS。修改后至少检查工作台、一个主从页面、一个列表页面和一个学习页面。

全部新增可展开频道必须遵守 [[主导航与Hash路由#主导航交互与样式契约|主导航交互与样式契约]]。财富值中心与配置中心共用 `channel-foundation.css` 中的 `gaip-main-menu-*` 布局：菜单高度按导航契约、18px 图标列、13px 图文间距、右侧 16px 的 12px 箭头、180ms 旋转；箭头使用绝对定位并按父项中心线对齐，不依赖标签宽度。父项需保留与普通菜单一致的 4px 透明左边框占位；二级当前态时父项只变前景色，绿色背景与左边框只属于当前二级项。频道 CSS 只保留原始图标和必要的二级内容差异。

侧栏“GLORY 百宝箱”由 `channel-regions.js` 统一识别并替换为共享横版图片，尺寸和底部定位由 `channel-foundation.css` 统一控制。不得在单个频道内复制图片或覆盖样式；当前基准为与侧栏底部背景容器同宽（展开态约 `208px`）、高度按 388:112 原图比例自适应（约 `60px`）、不额外设置圆角，`.ant-pro-layout .ant-pro-sider-footer` 的 `padding-block-end` 固定为 `0`，图片左右边与底部背景容器两端对齐并贴合底部。原 `Glory Advisor Intelligence Platform` 说明节点由共享脚本移除，CSS 同时提供隐藏兜底。

主导航滚动层由 `channel-regions.js` 标记为 `.gaip-sidebar-nav-scroll`，滚动条位置、颜色和百宝箱底图层级由 `channel-foundation.css` 统一控制：滚动层右边贴侧栏边缘，菜单内容坐标不变；默认 thumb 为 14% 中性灰、hover 28%、active 40%，宽 6px；滚动层层级高于百宝箱上延背景。完整基准见 [[主导航与Hash路由#滚动区域与百宝箱底图|滚动区域与百宝箱底图]]。

可复用组件在 `全局组件/index.html` 集中登记和预览。预览页直接调用真实组件工厂或加载组件所属的真实 CSS，不复制一套演示视觉样式。

组件字体同源：目录和海报分享独立文档均引用`shared/styles/global-font.css`，不再定义独立普惠字体面或品牌/代码字体覆盖。海报Canvas读取文档计算字体并在绘制前等待加载，保留原绘制字号/字重；全局标题字重规则保持独立职责。图片素材里的文字不会随CSS变更。参数见[[design-changes/component-catalog.json]]。

“真实弹窗预览”下另有用户明确要求的唯一子级“表单弹窗框架”（`parentId: modal-catalog`）。仅一个空表单示例，结构由目录提供，通过共享`adoptForm`接入标题、正文、关闭和底部按钮样式；不复制组件视觉规则、不加载业务页面、不登记成真实业务弹窗。示例按钮仅关闭展示，可重新展示，不提交数据。

新增业务弹窗仍按原源登记流程处理；抽屉与Agent主面板不纳入。目录试版视觉记录`design-changes/component-catalog.json`已标记撤回，不再作为交付目标。

弹窗滚动条最终采用“原生默认宽度＋淡色”：`global-font.css`使用标准原生属性，`global-modal.css`仅在共享定位宿主、弹窗组件及所属`.gaip-modal-popup`内覆盖滑块颜色，正文、列表、表格和输入框继承；不自定义像素宽度、圆角或滑块悬停绘制，不保证常态常驻，显隐由浏览器/系统管理。不支持标准颜色的旧浏览器采用系统颜色；不修改原滚动容器、内容padding或系统设置。弹窗淡色不扩展到页面/抽屉/Agent主面板。参数见`design-changes/modal-form-scroll.json`；独立浏览器测试`scripts/test-modal-scrollbar-browser.cjs`检查相对原生基线的宽度不变及颜色继承，不等同于来源页面验收。

弹窗内部复合表单控件由 `shared/scripts/modal-controls.js` / `shared/styles/modal-controls.css` 维护，采用 `.gaip-modal-controls` 和有明确归属的 `.gaip-modal-popup`，不能把主题挂到 body 或页面容器。普通输入仍复用 `global-modal.css`；新共享层为选择器、单选/多选、日期时间面板、清除图标等补齐状态。原生 select 的真实数据节点保留，代理仅负责弹窗内展示；日期仍由原输入的 min/max/step 约束。原站 Ant 节点不重写。新增弹窗自动识别标准宿主，任意自定义控件仍需接入语义契约，不能承诺靠类名猜测自动覆盖。详细范围及视觉缺口见 [[../../docs/modal-control-coverage|弹窗内部控件覆盖清单]]；视觉参数唯一台账为 `design-changes/modal-controls.json`。

共享表单字段由 `global-modal.js` 内的 `adoptFields` 随 `adoptForm` 接入，`global-modal.css` 拥有 `.gaip-form-control`、`.gaip-form-input-shell`、`.gaip-form-label` 和 `.gaip-form-help` 的公共视觉。这里只添加幂等类名，不替换真实字段；错误显示沿用业务状态，不使用原生 `:invalid` 提前染红必填框。文本域自动增高、字数节点及清除事件保留；选择器内部输入、工具栏搜索、树/表格/上传不接入普通文字控件。特殊复合控件可用 `data-gaip-form-field="exclude"` 显式排除。唯一参数记录见 `design-changes/shared-modal-fields.json`，业务页与预览继续调用同一来源。

弹窗必填星号由共享样式统一前置：Ant/07采用前置伪元素；新增线索关闭其旧后置伪元素；20终态、16节点及33/34公告的字面星号仅用CSS顺序调整，不移动React节点。可选标签不加标记，公告“至少一种语言”等分组约束保留在分组标题，不改业务required/ARIA或校验。参数见同一字段样式记录，独立几何与作用域测试见`scripts/test-modal-required-marker-browser.cjs`。

弹窗日期/范围后缀统一引用用户日历附件，纯时间后缀引用时间附件；两份共享资产集中于`shared/assets/modal-calendar.svg`与`modal-clock.svg`，直接绘制而非外部mask。Ant日期即使原来传入自定义下箭头也按日期用途绘制，纯时间保留clock-circle语义；原生控件按type区分。普通Select继续使用下箭头，不替换源节点或事件，参数见`design-changes/modal-controls.json`。来源与预览同用此层，页面、抽屉和Agent主面板不接入。

原生控件的共享展开面板保留所属弹窗 DOM 关系，通过 manual Popover 顶层避免 dialog 的 transform/overflow 影响；老引擎按实际包含块换算坐标，仍需验收其裁切限制。Ant Portal 不迁移、不接管定位。选择面板内部使用字段排除标记，避免日历年份框再被普通表单高度覆盖。22 新增线索由共享定位层取消旧源重复 translate，其他业务动画不变。状态见 [[../变更/当前未发布变更#弹窗控件错位续修]]。

共享原生选择面板 `.gaip-native-popup` 必须显式声明 `pointer-events:auto`：它是 Ant 外壳的直接子节点，不在 `.ant-modal-content` 的点击恢复范围内，否则会继承外壳的 `none` 而无法点击选项。不要为此取消整个 Ant 外壳的点击穿透。回归见 [[../变更/当前未发布变更#15 批量导入成员下拉点击修复]]。

带计数 Ant TextArea 的 affix 外壳由 `adoptFields` 标记 `.gaip-form-input-shell.gaip-form-textarea-shell`，复用公共输入框边框和状态；内部文本域去掉重复边框，保留业务自动高度、计数节点和限制。不得把单行输入的 `height:100%` 强加到多行字段。18 编辑对话名称与预览使用同一规则，见 [[../变更/当前未发布变更#18 编辑对话名称输入组件接入]]。

带计数多行字段的计数使用原节点的正常流独立行，位于textarea滚动视口之外；禁止仅用文本域底部padding配合固定计数，因为滚动中段仍会穿字。允许缩放的字段由共用外框手柄调节原textarea高度，CSS抑制内部原生手柄；不能再把计数与手柄当作互相独立的问题修改。自动增高/禁止缩放不新增手柄，拖动必须覆盖禁用、关闭和卸载清理。24底栏与表单通过同一边距变量抵消外层留白，不能再叠加按钮右侧边距；见[[../变更/当前未发布变更#计数文本域外框缩放手柄]]。

来源核验和新增接入契约见[[docs/modal-textarea-acceptance]]：新业务外壳可用`data-gaip-modal-part="counted-textarea"`，计数节点用`count`，避免仿造Ant私有类名。共享观察器响应语义标记与字段排除变化；fieldset禁用、动态退出和卸载均清理或禁用手柄。23/24原客户React/Ant组件的DOM回归已纳入常规测试，但不等于浏览器视觉验收。

表单搜索前缀与单行清除由 `modal-controls.js/css` 增强：复用现有源清除事件；缺少时增加同级按钮，不移动/包裹 React 输入。独立字段用 ResizeObserver 跟随原字段与宿主布局，退出弹窗时清理新增节点；搜索使用同一前缀槽，禁用与只读不允许清除。数字、多行计数与必选下拉约束保留。参数与状态只在对应台账/覆盖清单维护，见 [[../变更/当前未发布变更#表单控件一致性续修]]。

共享主标题 `.gaip-modal__title` 与文字子节点仍由 `global-modal.css` 拥有，全局重置排除这些节点。操作确认字体试点经用户验收后扩展到全页面：`global-font.css`唯一登记本地HarmonyOS Sans SC Regular/Bold，同一家族使用sans-serif兜底、禁止合成粗体；确认、表单分组和工作台不再另设字体面。正文/说明/按钮使用Regular，原弹窗主标题、表单分组及工作台强调标题使用Bold；保留原字号、颜色、布局和滚动条。所有正式入口及组件文档引用该共享源，新独立文档也需引用，不复制字体定义。参数见`design-changes/global-font.json`、`shared-modal-title.json`与`shared-modal-confirm.json`。`test-project-font-browser.cjs`核验代表元素的实际字体文件，不代表全部业务整页视觉验收。直接源预览在修改base前固定已声明的资源URL，后续业务资源仍从项目根解析。

表单弹窗与操作确认的公共视觉由 `shared/styles/global-modal.css` 和 `shared/scripts/global-modal.js` v1.2.0 共同维护：共用关闭 SVG 来源、32px 热区/16px 图标及状态、标题、外壳与按钮声明；表单使用 `adoptForm(dialog)`，不能调用会重建正文的 `setConfirmState()`。16 个现有表单由源选择器/精确业务标题接入，未来本地表单应在真实工厂挂载后显式调用 `adoptForm` 并照常登记。旧 Umi 只读，接入器保留原节点和监听器；共享规则使用限定于表单的高优先级选择器对抗旧频道样式，不改原确认规则。表单宽度、滚动、校验与操作语义继续由业务拥有。23 编辑资料通过共享按钮委托原取消/保存，不搬动 React 节点。正式入口及真实源预览加载同一资源，无预览专用样式副本。

全项目弹层盘点与真实源预览（2026-09-04）：共确认 52 类业务弹层，当前 35 类进入真实源 iframe 预览、0 类待接入、17 类不展示。组织架构日志、批量导入成员、调整节点、调整节点确认，以及公告管理的新建/编辑/删除确认均通过源 `@gaip-modal` 登记自动进入预览；新增本地源码弹窗统一遵循 [[../决策/ADR-004-弹窗源自登记与自动索引]]。17 类包括 6 类抽屉、用户明确排除的“GAIP Agent 助手主面板”和 10 类经正式 Hash 路由/当前源码复核确认已下线、不可达或并非独立弹窗的旧登记。原有共享与本地控制器继续调用同一 `open()`/`mount()`/`showModal()`；15 类 Umi 业务弹窗通过正式频道页面和真实 DOM 点击入口打开。预览页初始不创建 iframe，卡片进入可见区域或点击“立即加载”后才按需创建；真实弹窗出现后直接裁掉弹窗分支之外的频道页面 DOM，保留原弹窗、遮罩、Portal 和视觉，不使用页面覆盖层。配置中心直接源预览只建立空样式宿主，不渲染业务背景页。父预览页不保存弹窗 DOM/CSS，源入口或 CSS 修改后刷新即可同步；禁止用通用模板或复制 DOM 补齐。`全局组件/index.html` 已登记轻量入口卡片，实时读取同一目录的 35/0/17 数量，点击后打开独立预览页；组件首页自身不加载弹窗 iframe。视觉标准化盘点见 [[弹窗视觉规范与盘点]]。

全局弹层遮罩由 `shared/styles/global-modal-mask.css` 唯一提供视觉参数：颜色统一为 `rgba(0,0,0,.45)`，时长统一为 `160ms`，并覆盖原生 `dialog::backdrop`、Ant Modal / Drawer 与项目内明确登记的自定义遮罩。业务样式只保留尺寸、内容结构与 `z-index`；不得另写遮罩颜色、模糊或动效时长。弹窗预览页和 15 个正式根入口直接加载同一文件，因此正式源变化与预览同步；嵌套确认层使用同一视觉遮罩，但继续保留业务所需的局部层级。

普通弹窗的视口定位由 `shared/styles/global-modal-position.css` 唯一提供规则，`shared/scripts/global-modal-position.js` 负责识别当前和后续动态创建的弹窗宿主并添加 `data-gaip-modal-placement="center"`。Ant Modal 的默认 `top:100px`、原生 dialog 的局部顶部偏移会在接入后被统一为当前视口水平/垂直居中；桌面端安全边距 24px，640px 以下 12px，业务组件只继续负责宽高、内容、内部滚动和层级。抽屉与 `.agentModal___Nxp06` 主面板明确排除，调整管理员等嵌套确认只在父弹窗内部居中。真实弹窗预览统一使用 820px iframe 视口，登记项原有 `height` 不再参与可见舞台定位，避免预览容器高低不同产生假偏移。

弹窗显隐优先于定位：共享居中 CSS 的 `display: grid` 不得使用 `!important`，必须允许 rc-dialog 的内联 `display: none` 在关闭后隐藏全屏宿主，并排除 `[hidden]` 宿主。否则透明容器会继续拦截主导航和页面点击。该修复的 CSS 引用版本为 `20260907-1`。

## 确认与表单弹窗区域职责

本地业务可用`__GAIP_MODAL_COMPONENT__.createFieldFeedback(container, control)`创建共享错误节点，用返回的`set(message)`同步字段反馈与ARIA，关闭时调用`destroy()`清理自己拥有的节点。10新增成员直接使用；20只读React终态组件由`modal-controls.js#adoptTerminalValidation`进行必要字段前置校验，合格时仍执行原提交，原节点不移动；上传预览变化驱动凭证状态，关闭/卸载解除绑定。该接入器仅覆盖确切终态组件，不替换其他业务或服务端校验。

内联反馈由`global-modal.js#adoptFeedback`与共享CSS接入：Ant保留原控制区/动态additional/错误节点，本地保留隐藏错误节点；空态伪元素与可见错误占据同一反馈行，不用绝对定位覆盖内容。多行允许自然增加高度，永久帮助说明不吞掉错误预留行；原Ant负间距补偿和旧字段间隔不重复叠加。单选按字段组、公告按校验分组占位。新本地内联错误可声明`data-gaip-modal-part="field-error"`，错误须放在其字段父容器末尾并用hidden管理空态；不在确认、表格和弹窗外页面应用。参数只维护于`design-changes/shared-modal-fields.json`。

首错定位由`modal-controls.js`提供`revealInvalidField(field)`：仅处理`.gaip-modal-form`，原生选择器聚焦可见代理，并只滚动所属表单的可滚动祖先；字段及错误说明能一起容纳时整体露出。原生invalid事件同一轮只定位首项，关闭/销毁不抢焦点。公告显式调用此接口，其他自定义/Ant异步校验仍保留源行为，可在校验失败回调中接入；不由共享层重新验证业务或清除业务错误。

表单操作的内容文字与分组间距使用`global-modal.css`中限定`.gaip-modal-form`的规则，分组标题复用本地Medium字体面，字段正文与帮助继续复用既有body/caption token。只给表单增加分组/列间距变量，不修改确认组件共同基值；角色选择器排除嵌套`.gaip-modal`，防止表单里的二次确认被连带改动。标题间距只由标题区负责，上传等复合区去掉相邻padding叠加。精确参数见`design-changes/modal-interiors.json`。

- 内部组合部件由 `global-modal.js` 的 `adoptInteriors` 标记真实节点、`global-modal.css` 统一绘制；不再为预览单独定义列表、选项卡、提示、计数或导入部件样式。新控件可通过 `data-gaip-modal-part` 接入，已有业务节点和事件保持不变。
- 圆角按容器/控件分层，圆形标记除外；精确参数见 `design-changes/modal-interiors.json`，覆盖和验收缺口见 `docs/modal-control-coverage.md`。不影响信息展示、抽屉、Agent 主面板及页面表单。

本轮只适用于预览中的 6 类“操作确认”和 16 类“表单操作”；13 类“信息展示”、抽屉与 Agent 主面板不接入本轮区域标记。这里是语义划分，不是新视觉模板，也不表示滚动层已经迁移完毕。

| 层级 / 区域 | 职责 | 真实源码标记 |
| --- | --- | --- |
