## 修改规则

影响多个频道的规则放在共享层；频道专属视觉不放入全局 CSS。修改后至少检查工作台、一个主从页面、一个列表页面和一个学习页面。

侧栏“GLORY 百宝箱”由 `channel-regions.js` 统一识别并替换为共享图片，尺寸、裁切和圆角由 `channel-foundation.css` 统一控制。不得在单个频道内复制图片或覆盖样式；当前基准为宽 `176px`、高度按原图比例自适应（约 `136.68px`）、圆角 `11px`。

可复用组件在 `全局组件/index.html` 集中登记和预览。预览页只调用 `shared/` 中的真实组件实现，不复制一套演示样式。

## 全局操作日志

- 入口：全局顶栏顺序为操作日志 → 日期 → 用户头像。共享脚本将按钮插入日期节点前；日期缺失时回退到用户区前，顶栏重绘会校正顺序；登录状态无业务顶栏时不显示。
- 15 个根入口统一加载日志 CSS，并依次加载 Mock、Excel 导出器、UI 脚本。不要在单个 HTML 内复制实现，不新增日志 HTML，不改频道配置或 Hash 路由。
- 弹窗：原生 `dialog.showModal()`，顶层遮罩与背景 inert；关闭按钮或 Esc 关闭，恢复焦点与页面滚动。保留当前频道、原有输入及日志筛选条件。
- 字段：序号、操作时间、操作人/IP、模块、操作类型、操作内容、变更前、变更后。模块为公告管理/资讯中心，操作类型为新增/编辑/删除/查看。
- 数据：28 条固定模拟记录，虚构账号与 TEST-NET IP，不访问服务器、不捕获真实用户行为、不写本地存储。未来接入真实审计需另行设计权限与服务端记录。
- 导出：筛选后的全部记录（非仅当前页）导出为 `.xlsx`，长内容不截断；纯本地 OOXML/ZIP，单元格统一为文本，避免公式注入。
- 资源：入口使用用户提供的 `shared/assets/operation-log.svg`（原附件为 Downloads/ICON/通用/操作日志.svg），原始形状与 #2F3640 填充保留；显示 16×16px、opacity 1。原 Lucide 图标已替换并移除。复用现有海报分享目录中的下载、关闭 SVG。
- 按钮：32px 高、32px 圆角、14px 文字、桌面左右 12px 内边距、中性灰浅底；文字在默认/悬停/展开态均为 #2F3640，悬停/展开仅改变底色与边框。保留 1000px 以下左右 6px 内边距、600px 以下仅图标的适配。
- 顶栏对齐：由 `shared/styles/channel-foundation.css` 统一三个组的 32px 高度、inline-flex 居中与 20px 文本行高；桌面组间距 20px，1000px 以下统一 12px；用户区内部仍为 8px 间距，头像大小和日期原有颜色不变。沿用全局字体，不新增字体定义。
- 用户区分割线：左侧使用 1px 浅灰伪元素，高度复用 `--gaip-app-header-height`（56px），贯穿顶栏。用户区额外左外边距桌面 28px/1000px 以下 20px，与原组间距合计 48px/32px，线两侧各约 24px/16px；伪元素不接收点击。框架 CSS 缓存版本为 `20260831-3`。
- 自动检查：`scripts/test-operation-log.cjs`（需要测试用 `jsdom`，不作为运行时依赖）覆盖 DOM 生命周期、筛选/日期/分页、展开、XLSX 结构与 15 个入口引用。
- 日志控件边框：搜索/日期/筛选及分页下拉使用 `--log-brand` 统一悬停与聚焦边框，无额外阴影/外框；日期错误保留红边，按钮和表格的键盘焦点框不变。日志 CSS 最新版本 `20260831-6`；此规则仅作用于共享日志组件。
- 筛选图标：复用原站 Ant Design outlined 的 SVG path，集中在 `shared/assets/control-{down,search,calendar}.svg`；由日志 CSS 背景图引用，下拉 12px、搜索/日历 14px。日期保留原生控件与点击热区，不支持 WebKit 指示器的浏览器保留原生日历图标。日志 CSS 版本 `20260831-5`，JS 保持 `20260831-4`；本轮代码检查通过，视觉/原生展开仍待确认。
- 2026-08-31 发布回归：本地 HTTP 预览已确认日志弹窗遮罩、桌面布局、筛选和关闭按钮；工作台 → 资讯 → 产品、客户入口 → 工作台 → 资讯 → 保单 → 学习路径的主文档 loaderId 不变，日志入口始终唯一。自动化键盘操作未能可靠确认原生 Esc 和焦点循环，保留手工确认项。
