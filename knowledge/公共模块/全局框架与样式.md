## 修改规则

影响多个频道的规则放在共享层；频道专属视觉不放入全局 CSS。修改后至少检查工作台、一个主从页面、一个列表页面和一个学习页面。

全部新增可展开频道必须遵守 [[主导航与Hash路由#主导航交互与样式契约|主导航交互与样式契约]]。财富值中心与配置中心共用 `channel-foundation.css` 中的 `gaip-main-menu-*` 布局：40px 高、18px 图标列、13px 图文间距、右侧 16px 的 12px 箭头、180ms 旋转；箭头使用绝对定位并按父项中心线对齐，不依赖标签宽度。父项需保留与普通菜单一致的 4px 透明左边框占位；二级当前态时父项只变前景色，绿色背景与左边框只属于当前二级项。频道 CSS 只保留原始图标和必要的二级内容差异。

侧栏“GLORY 百宝箱”由 `channel-regions.js` 统一识别并替换为共享横版图片，尺寸和底部定位由 `channel-foundation.css` 统一控制。不得在单个频道内复制图片或覆盖样式；当前基准为与侧栏底部背景容器同宽（展开态约 `208px`）、高度按 388:112 原图比例自适应（约 `60px`）、不额外设置圆角，`.ant-pro-layout .ant-pro-sider-footer` 的 `padding-block-end` 固定为 `0`，图片左右边与底部背景容器两端对齐并贴合底部。原 `Glory Advisor Intelligence Platform` 说明节点由共享脚本移除，CSS 同时提供隐藏兜底。

主导航滚动层由 `channel-regions.js` 标记为 `.gaip-sidebar-nav-scroll`，滚动条位置、颜色和百宝箱底图层级由 `channel-foundation.css` 统一控制：滚动层右边贴侧栏边缘，菜单内容坐标不变；默认 thumb 为 14% 中性灰、hover 28%、active 40%，宽 6px；滚动层层级高于百宝箱上延背景。完整基准见 [[主导航与Hash路由#滚动区域与百宝箱底图|滚动区域与百宝箱底图]]。

可复用组件在 `全局组件/index.html` 集中登记和预览。预览页直接调用真实组件工厂或加载组件所属的真实 CSS，不复制一套演示视觉样式。

全项目弹层盘点与真实源预览（2026-09-04）：共确认 52 类业务弹层，当前 35 类进入真实源 iframe 预览、0 类待接入、17 类不展示。组织架构日志、批量导入成员、调整节点、调整节点确认，以及公告管理的新建/编辑/删除确认均通过源 `@gaip-modal` 登记自动进入预览；新增本地源码弹窗统一遵循 [[../决策/ADR-004-弹窗源自登记与自动索引]]。17 类包括 6 类抽屉、用户明确排除的“GAIP Agent 助手主面板”和 10 类经正式 Hash 路由/当前源码复核确认已下线、不可达或并非独立弹窗的旧登记。原有共享与本地控制器继续调用同一 `open()`/`mount()`/`showModal()`；15 类 Umi 业务弹窗通过正式频道页面和真实 DOM 点击入口打开。预览页初始不创建 iframe，卡片进入可见区域或点击“立即加载”后才按需创建；真实弹窗出现后直接裁掉弹窗分支之外的频道页面 DOM，保留原弹窗、遮罩、Portal 和视觉，不使用页面覆盖层。配置中心直接源预览只建立空样式宿主，不渲染业务背景页。父预览页不保存弹窗 DOM/CSS，源入口或 CSS 修改后刷新即可同步；禁止用通用模板或复制 DOM 补齐。`全局组件/index.html` 已登记轻量入口卡片，实时读取同一目录的 35/0/17 数量，点击后打开独立预览页；组件首页自身不加载弹窗 iframe。视觉标准化盘点见 [[弹窗视觉规范与盘点]]。

全局弹层遮罩由 `shared/styles/global-modal-mask.css` 唯一提供视觉参数：颜色统一为 `rgba(0,0,0,.45)`，时长统一为 `160ms`，并覆盖原生 `dialog::backdrop`、Ant Modal / Drawer 与项目内明确登记的自定义遮罩。业务样式只保留尺寸、内容结构与 `z-index`；不得另写遮罩颜色、模糊或动效时长。弹窗预览页和 15 个正式根入口直接加载同一文件，因此正式源变化与预览同步；嵌套确认层使用同一视觉遮罩，但继续保留业务所需的局部层级。

普通弹窗的视口定位由 `shared/styles/global-modal-position.css` 唯一提供规则，`shared/scripts/global-modal-position.js` 负责识别当前和后续动态创建的弹窗宿主并添加 `data-gaip-modal-placement="center"`。Ant Modal 的默认 `top:100px`、原生 dialog 的局部顶部偏移会在接入后被统一为当前视口水平/垂直居中；桌面端安全边距 24px，640px 以下 12px，业务组件只继续负责宽高、内容、内部滚动和层级。抽屉与 `.agentModal___Nxp06` 主面板明确排除，调整管理员等嵌套确认只在父弹窗内部居中。真实弹窗预览统一使用 820px iframe 视口，登记项原有 `height` 不再参与可见舞台定位，避免预览容器高低不同产生假偏移。

弹窗显隐优先于定位：共享居中 CSS 的 `display: grid` 不得使用 `!important`，必须允许 rc-dialog 的内联 `display: none` 在关闭后隐藏全屏宿主，并排除 `[hidden]` 宿主。否则透明容器会继续拦截主导航和页面点击。该修复的 CSS 引用版本为 `20260907-1`。

## 共享操作日志

- 入口：2026-09-01 起全局顶栏不再显示“操作日志”按钮，顶栏仅保留日期、分割线和用户区。共享脚本启动时会清理旧缓存遗留的 `.gaip-log-trigger`，且不再监听顶栏重绘；当前只有配置中心“操作日志”二级页使用本组件。组织架构页右上角同名按钮属于配置中心页面专属日志，不得调用本组件。
- 全部根入口（包括新增 `配置中心.html`）统一加载日志 CSS，并依次加载 Mock、Excel 导出器、UI 脚本。不要在单个 HTML 内复制实现。配置中心“操作日志”二级页通过 `mount(host)` 复用同一实现，不另建操作日志 HTML。
- 弹窗：原生 `dialog.showModal()`，顶层遮罩与背景 inert；关闭按钮或 Esc 关闭，恢复焦点与页面滚动。保留当前频道、原有输入及日志筛选条件。
- 字段：序号、操作时间、操作人/IP、模块、操作类型、操作内容、变更前、变更后。模块为公告管理/资讯中心，操作类型为新增/编辑/删除/查看。
- 数据：28 条固定模拟记录，虚构账号与 TEST-NET IP，不访问服务器、不捕获真实用户行为、不写本地存储。未来接入真实审计需另行设计权限与服务端记录。
- 导出：筛选后的全部记录（非仅当前页）导出为 `.xlsx`，长内容不截断；纯本地 OOXML/ZIP，单元格统一为文本，避免公式注入。
- 资源：已删除仅供全局入口使用的 `shared/assets/operation-log.svg`；日志页面继续复用海报分享目录中的下载、关闭 SVG，以及三个本地筛选控件 SVG。
- 顶栏对齐：由 `shared/styles/channel-foundation.css` 统一日期和用户区的 32px 高度、inline-flex 居中与 20px 文本行高；用户区内部仍为 8px 间距，头像大小和日期原有颜色不变。沿用全局字体，不新增字体定义。
- 用户区分割线：左侧使用 1px 浅灰伪元素，高度为 20px，与顶栏文字行高一致并垂直居中。用户区额外左外边距桌面 28px/1000px 以下 20px，与原组间距合计 48px/32px，线两侧各约 24px/16px；伪元素不接收点击。框架 CSS 缓存版本为 `20260901-7`。
- 自动检查：`scripts/test-operation-log.cjs`（需要测试用 `jsdom`，不作为运行时依赖）覆盖全局入口缺席及旧入口清理、配置中心复用控制器、筛选/日期/分页、展开、XLSX 结构与全部根入口引用。
- 日志控件边框：搜索/日期/筛选及分页下拉使用 `--log-brand` 统一悬停与聚焦边框，无额外阴影/外框；日期错误保留红边。日志 CSS 最新版本 `20260901-1`；此规则仅作用于共享日志组件。
- 筛选图标：复用原站 Ant Design outlined 的 SVG path，集中在 `shared/assets/control-{down,search,calendar}.svg`；由日志 CSS 背景图引用，下拉 12px、搜索/日历 14px。日期保留原生控件与点击热区，不支持 WebKit 指示器的浏览器保留原生日历图标。
- 2026-08-31 发布回归：本地 HTTP 预览已确认日志弹窗遮罩、桌面布局、筛选和关闭按钮；工作台 → 资讯 → 产品、客户入口 → 工作台 → 资讯 → 保单 → 学习路径的主文档 loaderId 不变，日志入口始终唯一。自动化键盘操作未能可靠确认原生 Esc 和焦点循环，保留手工确认项。
- 发布记录见 [[../变更/2026-08-31-工作台与共享组件同步#操作日志|全局操作日志发布记录]]；控件图标及边框修正已随 `5d597a4` 发布，见 [[../变更/2026-08-31-工作台对齐与共享控件修复#操作日志筛选图标与聚焦边框|控件修正记录]]。
