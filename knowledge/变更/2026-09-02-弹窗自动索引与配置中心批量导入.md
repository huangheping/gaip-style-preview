# 2026-09-02 弹窗自动索引与配置中心批量导入

## 发布结果

- 功能提交：`d7d6dc5`（`Publish modal catalog and config import updates`）。
- 分支：`main`。
- GitHub Pages 已以完整提交 `d7d6dc5dab096a464aeefe8bb719df2f9152322a` 构建成功。
- 本次正式变更共 45 个文件、1867 行新增、182 行删除。

## 配置中心

- 组织架构新增“批量导入成员”弹窗内三步流程：选择渠道与目标节点、校验并确认、导入结果。
- 发布固定 9 列、100 行数据区的 Excel 模板，以及用户提供的模板/上传图标；本地示例覆盖 18 行校验、2 条成功、16 条失败、部分成功、失败明细下载和继续导入。
- 三步弹窗统一为桌面 `1100 × 840px` 安全尺寸，标题、进度和底部操作固定；长组织树与校验表格只在各自区域滚动。
- 成员表新增“身份”列，按人管、佣金、线索管理、线索跟进显示紧凑标签，并复用成员编辑与管理员设置的同一角色状态。
- 组织架构右上角恢复独立操作日志弹窗，与“配置中心 → 操作日志”二级频道的数据和控制器隔离；表格使用七列固定布局、独立双向滚动、不透明吸顶表头与固定分页。
- 独立日志增加“导出成员名单”展示状态；真实多节点导出、8 列最终字段模型和三个新增渠道仍未实现。

## 弹窗目录与预览

- 新增 `@gaip-modal` 源自登记规范、`scripts/generate-modal-catalog.cjs` 生成器、共享弹窗注册器和自动生成索引；新增本地弹窗不再需要在预览页维护第二套分支。
- `AGENTS.md` 与 [[../决策/ADR-004-弹窗源自登记与自动索引|ADR-004]] 固化登记、生成、测试及抽屉排除规则。
- 全局组件目录新增“真实弹窗预览”入口，直接读取运行时目录数量，不在首页加载弹窗 iframe。
- 弹窗目录现为 47 类：30 类真实可预览、0 类待接入、17 类不展示；其中 15 类由正式频道 Hash 路由和真实点击入口触发。
- 独立预览页使用 `IntersectionObserver` 按视口创建 iframe，并提供“立即加载”和失败重试；配置中心 6 类直接源弹窗使用无背景空宿主，正式频道弹窗打开后删除频道正文 DOM。
- 修复 AI Agent 对话重命名、线索终态、产品专家、活动报名与入职完成等真实入口识别。
