# 2026-09-02 配置中心与共享导航更新

## 发布结果

- 功能提交：`716aa78`（`Publish configuration center and shared navigation updates`）。
- 分支：`main`。
- GitHub Pages 已以完整提交 `716aa7882fc779ac16acd1e1222821e028b02efd` 构建成功。

- 本次正式变更共 63 个文件、4429 行新增、332 行删除。

## 主要更新

### 配置中心

- 新增根入口 `配置中心.html` 与完整 `features/config-center/` 频道实现。
- 组织架构沿用原站 DOM、CSS 和图标，使用示例成员数据完成组织树、搜索、分页、部门增改删、成员编辑、管理员设置与 Excel 导出。
- 新增操作日志二级页；组织页日志按钮和日志功能保留，全局顶栏操作日志入口移除。
- 成员弹窗固定标题与底部操作区，只让中间表单滚动；管理员、佣金与线索角色按既定约束同步。
- 配置中心组织架构、操作日志与四类弹窗共享正式控制器，不复制业务结构。

### 主导航与全局框架

- 配置中心与财富值中心父导航统一为纯展开/收起，叶子项继续 Hash 无刷新切换。
- 固化父子当前态、图标与文字坐标、键盘行为、跨频道隔离和滚动层规则。
- 修复财富值子项当前态切换配置中心时的误跳；配置图标默认态和当前态统一使用原始 SVG。
- 用户区分割线缩短并保持垂直居中；删除全局顶栏日志触发器及已不再使用的图标资源。
- 配置中心覆盖层不再阻断原 AI Agent 入口。

### 财富值与频道页面

- “我的财富值”概览发布用户提供的 `wealth-overview-user-wide-20260901.jpg`，页面以 `center / cover` 使用；候选图继续只保留本地。
- 活动中心同步真实弹窗打开能力及两个正式图片资源。
- 方案、资讯、财富值和 AI Agent 的本地控制器补齐真实弹窗预览入口，不改变既有业务路由含义。

### 全局弹窗预览

- `全局组件/弹窗预览.html` 盘点 45 类弹层：28 类可通过真实共享 API、完整本地控制器或正式 Hash 页面真实点击入口预览；0 类待接入；17 类按抽屉、用户排除或已下线/不可达原因登记但不展示。
- 其中 15 类通过正式频道路由触发，iframe 仅负责隔离真实页面和弹窗；不复制 DOM/CSS，不改只读 `web/`。
- 增加加载队列、成功/失败状态回报和预览专用中性底层，避免频道正文干扰弹窗检查。
