# 2026-09-17 学习中心直播与共享控件更新

## 发布结果

- 功能提交：`b619611a471f79ec16157f26e7f354ba2c8b78c0`（`feat: add learning live cards and shared controls`）。
- 正式发布 73 个文件，共 4055 行新增、297 行删除。
- GitHub Pages 对应构建 `35182107262` 已成功完成。
- 线上入口：https://huangheping.github.io/gaip-style-preview/

## 主要内容

- 学习中心新增直播横卡、直播管理、本地状态与日志能力：单场半宽靠左、双场并排、更多直播按组切换，无直播时整体隐藏。
- 直播示例使用两张 750×320 正式封面和黑底金色视频标签；公开标题、简介、开播倒计时及“直播中”状态独立展示。
- 新增共享轮播控件，活动中心保留原 Slick 行为和指示器，学习中心使用圆形箭头与短条指示点；组件目录使用同一实现。
- 共享下划线 Tab 扩展到薄荷入职引导和方案中心，数量后缀保持 Regular、选中名称使用 Bold；组件目录展示拆分为独立预览卡。
- 共享折叠多选视觉与筛选器统一；所属组织选择树首次打开默认收起，仅在已有选择或搜索时展开必要路径。
- 共享表格增加可选不分页，操作日志、弹窗索引、频道资源、规范文档和视觉参数台账同步更新。

## 验证

- 直播领域与 Mock 回归通过：8 条示例、15 条日志、草稿/上架/排期/下架、权限、增量迁移、数据隔离及存储失败保护正常。

- 组件目录、课程管理、组织树默认收起、弹窗预览、JS 语法、JSON、SVG、图片尺寸和 `git diff --check` 均通过。
