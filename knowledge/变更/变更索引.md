## 已发布

已完成发布的变更按 `YYYY-MM-DD-主题.md` 新建并链接在这里。代码提交历史以 Git 为准，全局视觉历史另见 [[docs/global-style-changelog|全局样式修改记录]]。

## 状态约定

- `计划中`：尚未修改代码。
- `进行中`：已经开始修改。
- `待验证`：实现完成但回归未完成。
- `待发布`：验证通过，尚未提交或推送。
- `已发布`：已记录 Git commit。
- `暂停`：主动保留但当前不继续。

一个条目同一时刻只能有一个状态。
