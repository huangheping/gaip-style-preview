# 方案中心

- 入口：`channels/proposal-center/index.html`
- Hash：`#/proposal`
- 专属实现：`channels/proposal-center/proposal-center.css`、`channels/proposal-center/proposal-center.js`
- 专属素材：`channels/proposal-center/assets/icons/plan-tag-close.svg`
- 资源登记：`shared/config/channels.js`
- “全部方案 / 我的方案记录”Tab接入共享 `global-tabs.js/css`；数量后缀复用共享常规字重与间距，原切换及筛选事件保留。见 [[../../docs/tabs-spec|下划线Tab规范]]。
- “我的方案记录”只有“已归属”和“待确认客户归属”使用共享非表格状态标签 `components/status-tag/global-status-tag.css`；客户姓名、方案 ID、顶部筛选、左侧计数和操作按钮均不是标签。规格见 [[../../docs/status-tag-spec|状态标签规范]]。
- 关联：[[../公共模块/频道资源加载|频道资源加载]]、[[../公共模块/主导航与Hash路由|主导航与 Hash 路由]]、[[../公共模块/本地Mock系统|本地 Mock 系统]]

## 主页面字号层级

- 主标题使用20px，记录卡片标题使用16px，分类与操作使用14px，记录数量、汇总、方案ID、客户姓名、归属状态和时间使用12px。
- 本规则覆盖方案中心主页面与“我的方案记录”主列表；附件预览内部排版是已有独立场景，不因本轮字号收敛而调整。

## 记录视图滚动契约

- “我的方案记录”占用频道标题与 Tab 以下的视口剩余高度；筛选工具栏与记录汇总保持可见。
- 左侧方案分类和右侧记录列表是两个独立纵向滚动区，只有各自内容超出时才显示滚动条；不得让记录列表继续撑高整个频道页面。
- 右侧滚动槽使用主区右侧内边距承载，卡片内容宽度不因滚动条出现或稳定占位而改变。
- 滚动实现位于 `proposal-center.css` 的 `.gaip-record-layout`、`.gaip-record-main`、`.gaip-record-sidebar` 和 `.gaip-record-list`，不得用模拟滚动条替代原生滚动。

## 修改边界

`channels/proposal-center/` 是方案中心业务实现唯一源码。根 HTML 只是入口薄壳；共享状态标签样式归 `components/status-tag/`，方案中心通过频道配置加载，保证从任何频道 Hash 切换后仍显示同一新版。

## 历史风险

- 直接修改 `channels/proposal-center/index.html` 会造成其他入口仍加载旧实现。
- 用 `location.href` 切换入口会让整个应用刷新。
- 只在方案中心入口加载专属资源，会让 Hash 无刷新切换时丢失改版。
