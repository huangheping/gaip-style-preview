# 财富值中心

- 入口：`财富值中心.html`
- 路由：复用 `#/workspace`，通过 `gaip-channel=wealth` 区分虚拟频道
- 子频道：`gaip-view=import-workbench`、`import-records`、`my-wealth`
- 专属实现：`features/wealth-center/wealth-center.css`、`wealth-center.js`、`wealth-nav.js`
- 本地 Mock：`features/wealth-center/mock-data.js`
- 本地素材：`assets/wealth-center/wealth-overview.jpg`（旧版保留）、`assets/wealth-center/wealth-overview-user-wide.jpg`（我的财富值概览当前本地背景，同系列旧版已删除）、`assets/wealth-center/wealth-overview-mkv-refined-walnut-glass-v5-20260901.png`、`wealth-overview-envelope-trial-20260901.png` 与其余 `wealth-overview-*.png/.jpg`（不同方案候选背景，未引用）、`assets/wealth-center/hkd-currency.svg`
- 主导航：使用参考站 `MenuIconWealth` 钱包线框和 Ant 内联子菜单结构；父项左内边距 `24px` 且保留普通主菜单的 `4px` 左边框占位，子项左内边距 `55px`。任一财富值二级项处于当前态时，父级只将文字、图标和箭头变为品牌绿，背景和左边框保持透明；绿色浅底与左边框仅属于当前二级项，与配置中心逻辑一致。父项 hover 使用灰色底。父项与配置中心共用 `gaip-main-menu-*` 契约，只负责展开/收起，不打开默认子页；箭头固定在右侧 `16px` 并以 180ms 旋转，Enter/空格切换、Esc 收起。

## 页面结构

- 导入工作台：批次设置、四步流程、文件校验统计、结果筛选、文件详情抽屉。
- 导入记录：批次筛选、批次表格、当前批次文件明细、保司关键词弹窗。
- 我的财富值：本月与累计概览、港币标识、财富值构成、范围与类型筛选、明细表格。当前本地使用用户最新提供的 `3416×420` 超宽背景原图，唯一同系列文件为 `wealth-overview-user-wide.jpg`，以 `center / cover` 取景，不调色；图片 URL 使用 `v=20260902-2` 强制刷新。概览高度为 `236px`，构成卡片使用 90% 白色半透底。“本月已发”与“累计已发”之间显示 `44px` 高短竖线，两侧间距各为 `56px`，`1500px` 以下各为 `44px`。本页明细表头背景为 `#F8F5F3`，该颜色仅限 `.gaip-wealth-my-table`。

## 修改边界

财富值中心沿用当前 Umi 顶栏和侧栏，是虚拟频道覆盖层。不得新增独立 Umi 路由或修改 `web/` 构建产物；跨频道切换必须保持 Hash 无刷新，演示数据必须来自本地 Mock。

离开财富值频道的捕获监听必须忽略 `[data-gaip-main-menu-toggle]`。否则在财富值子项为当前态时点击配置中心父级，会先卸载财富值频道并造成错误跳转；只有普通频道项和二级链接可以触发真实导航。
