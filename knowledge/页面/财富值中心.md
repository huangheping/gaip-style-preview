# 财富值中心

- 入口：`财富值中心.html`
- 路由：复用 `#/workspace`，通过 `gaip-channel=wealth` 区分虚拟频道
- 子频道：`gaip-view=import-workbench`、`import-records`、`my-wealth`
- 专属实现：`features/wealth-center/wealth-center.css`、`wealth-center.js`、`wealth-nav.js`
- 本地 Mock：`features/wealth-center/mock-data.js`
- 本地素材：`assets/wealth-center/wealth-overview.jpg`、`assets/wealth-center/hkd-currency.svg`
- 主导航：使用参考站 `MenuIconWealth` 钱包线框和 Ant 内联子菜单结构；父项左内边距 `24px` 且保留普通主菜单的 `4px` 左边框占位，子项左内边距 `55px`，父项 hover/选中态与普通主菜单一致，支持鼠标与键盘收起展开；展开态显示向上箭头，收起态显示向下箭头。
- 关联：[[工作台总览]]、[[../公共模块/主导航与Hash路由|主导航与 Hash 路由]]、[[../公共模块/频道资源加载|频道资源加载]]、[[../公共模块/本地Mock系统|本地 Mock 系统]]

## 页面结构

- 导入工作台：批次设置、四步流程、文件校验统计、结果筛选、文件详情抽屉。
- 导入记录：批次筛选、批次表格、当前批次文件明细、保司关键词弹窗。
- 我的财富值：本月与累计概览、港币标识、财富值构成、范围与类型筛选、明细表格。

## 修改边界

财富值中心沿用当前 Umi 顶栏和侧栏，是虚拟频道覆盖层。不得新增独立 Umi 路由或修改 `web/` 构建产物；跨频道切换必须保持 Hash 无刷新，演示数据必须来自本地 Mock。
