# 配置中心

## 入口与路由

- 入口：`配置中心.html`。一级菜单位于主导航末尾，可展开/收起。
- 一级父项与财富值中心共用 `gaip-main-menu-*` 契约，只展开/收起二级项，不改变 Hash；箭头固定在右侧 `16px` 并旋转，位置不随文字长度变化。配置图标默认态直接引用与线上构建包逐字节一致的 `features/config-center/assets/organization.svg`，当前态直接对同一 `<img>` 使用 CSS 滤镜，使图标与文字同步变绿；不在 JS 中手绘 path，也不依赖外部 SVG 蒙版。
- 注册表：`shared/config/channels.js` 的 `config`；`views` 为二级导航唯一来源。
- 组织架构：`#/workspace?gaip-channel=config&gaip-view=organization`。
- 公告管理：`#/workspace?gaip-channel=config&gaip-view=announcement-management`。
- 操作日志：`#/workspace?gaip-channel=config&gaip-view=operation-log`。
- 沿用 Umi Hash SPA，地址栏文件名由共享导航同步，不加载新的文档。

## 页面实现

- 唯一源码位于 `features/config-center/`。`source-markup.js` 保存原站 DOM 模板（人员字段替换为示例）；`ant-source.css` 提供原站运行时组件基线；`config-center-content.css` 包含完整配置中心主体样式与本地内容覆盖；`config-center.css` 只包含主导航、顶部栏、顶部搜索和 Hash 页面挂载骨架；`config-center.js` 承载交互与挂载。`organization-source.css` 仅保留为未拆分的原站样式对照快照，不参与运行时加载。
- 原站 CSS 使用 `@scope (.gaip-config-page)` 限定范围。图标直接来自原站：`assets/organization.svg`、`folder.png`、`delete.svg`，其余原站内联图标保留，不重新绘制。
- 2026-08-31 根据参考站 `/web/config/organization` 核对：当前账号的配置中心只有“组织架构”二级项；“操作日志”为用户要求新增。
- 配置中心新增独立“公告管理”二级页，页面数据和控制器位于 `announcement-management-data.js` / `announcement-management-view.js`，视觉位于 `announcement-management.css`；不混入组织架构或两个既有操作日志的状态。内容区顶部使用与其他配置中心频道一致的浅灰分割线。列表包含序号、标题、生效时间段、状态和操作，按每页 10 条分页且每页序号从 1 开始；分页复用 Ant 表格分页，超过 7 页时保留首尾页、当前页相邻页和前后 5 页跳转省略号，上一页/下一页固定显示 `14px` 方向图标。标题按简体中文、繁体中文、英文依次兜底，列表保持单行省略；hover 或键盘聚焦后以 Tooltip 分语言完整展示所有已填写标题。首屏提供三种语言均为 100 字符的边界 Mock。生效时间以“开始 / 结束”标签对齐为两行，并用等宽数字降低时间戳阅读负担。状态根据当前时间自动计算为“未开始 / 展示中 / 已下架”。
- 公告新建与编辑复用项目 `formModal____MTrk` 的 Ant 弹窗头部/正文/底部层级，表单只位于 body，独立 footer 与 body 同级；标题和底部操作区固定，只有 body 在小视口内部滚动。操作按钮保留公告原紧凑规格 `88×40px / 14px`，取消为白底描边，保存为品牌绿底白字。表单提供简体中文、繁体中文、英文三个 100 字标题及开始/结束日期时间；标题使用 48–112px 自动增高文本域，达到上限后在字段内部滚动；时间段按两个端点分组，每组日期和时间同行，中间使用 `~` 连接。日期、时间控件的可见图标统一为 `20×20px` 项目 SVG，并覆盖在仍可点击的原生选择器热区上。至少填写一种语言，且结束时间必须晚于开始时间。新建记录插入列表首位并回到第 1 页；编辑更新当前记录。“展示中”的公告删除按钮置灰并提供原因说明；未开始和已下架记录删除前使用二次确认，确认按钮使用 Ant 全局错误色变量，确认后在当前本地会话移除。
- 新建、编辑与删除确认分别通过 `config-announcement-create`、`config-announcement-edit`、`config-announcement-delete` 源登记进入全局弹窗预览，均调用 `__GAIP_ANNOUNCEMENT_MANAGEMENT__` 的真实控制器和同一 DOM/CSS；不复制预览专用弹窗。
- 组织架构保留六个渠道（薄荷经纪人、Glory品牌顾问、外部机构渠道、线上渠道、小仓、荣耀经纪人）、部门导航、成员搜索/表格、Excel 导出与成员编辑入口。“批量导入成员”属于组织架构全局入口，因为流程会在第一步重新选择“渠道 → 目标节点”，Excel 模板自身不包含渠道或节点字段；入口不隶属于当前六大渠道 Tab。批量导入在同一弹窗内完成“选择导入范围 → 校验并确认 → 导入结果”，不再使用独立新页面。第一步的渠道使用单选下拉，目标节点使用可搜索、可展开收起的单选树，范围卡片右上持续展示完整路径；切换渠道时重置为新渠道根节点。上传区采用紧凑描边按钮，10MB 与 `.xlsx` / `.xls` 格式限制集中显示在按钮旁，选中文件后在下一行显示回形针和文件名；示例流程位于标题右侧，模板下载提示条只保留表头与单次数量说明。第一步还支持将文件拖入弹窗的标题、步骤、内容或底部任意区域，进入时整窗覆盖 `#24D4C9` 品牌色半透明遮罩与“松开以上传并识别文件”提示，离开或放下后立即清除，放下后复用点击上传相同的格式和大小校验。第三步先展示完成反馈和纵向后续操作，再将导入节点、统计及说明收拢到一个结果详情卡片，三个统计块统一为 `68px` 高；部分失败使用琥珀色感叹号和“导入完成，部分失败”标题，“下载失败明细”为带下载图标的绿色主按钮，“继续导入”为居中的下划线文字操作，全部成功则使用绿色对勾和“批量导入已完成”标题并只保留“继续导入”。本地设计验收用的“部分失败 / 全部成功”切换位于白色弹窗下方的遮罩区域，透明的弹窗点击边界覆盖该区域，并为切换器显式恢复点击事件，因此可直接切换且不占用正式结果内容，也不改变真实导入结果。弹窗固定标题和三步进度，前两步保留固定底部操作区，第三步操作位于结果正文；并以校验预览步骤的最大内容高度统一三步外框；桌面宽 `1100px`、高 `840px`（受视口安全边距限制），主体不纵向滚动，长组织树在树区域内独立滚动，宽表仅保留横向滚动。
- 批量导入模板位于 `features/config-center/assets/批量人员导入模板.xlsx`，固定字段顺序为“域账号、用户姓名、香港、新加坡、美国、大陆、百慕大、转介绍人、管理员”，支持 100 行成员数据及字段下拉约束；模板提示条使用用户提供并纳入项目的 `features/config-center/assets/bulk-import-template-xlsx.svg`，上传按钮使用用户提供的 `features/config-center/assets/bulk-import-upload.svg`。页面接受 `.xlsx` / `.xls`、限制 10MB，并提供确定性的本地示例文件入口。校验预览以 18 行 Mock 展示长表格内部滚动，其中 2 条可导入、16 条失败；失败原因覆盖渠道内重复、UA 不存在、停用账号、地区错误、文件内重复、缺少账号/姓名和枚举错误。第二步以目标节点为主信息，人数统计和失败处理说明合并为弱提示；校验表第二列表头为“用户姓名”，转介绍人“无”和管理员“否”统一显示为 `-`，但保留原值参与校验及导入；表格独立双向滚动且表头吸顶，底部操作按“上一步 → 下载失败明细 → 确认导入”排列，其中下载失败明细为带下载图标的描边按钮。失败行不阻止有效行导入。确认后两个有效成员写入所选节点的当前会话成员列表，结果页支持失败明细下载与继续导入，刷新页面后重置。
- 本地组织根节点使用 24 名虚构成员，保留原站捕获的部门名称与层级；成员表不分页，一次展示当前节点或搜索结果的全部成员。工具栏固定在表格上方，表格在剩余内容高度内独立双向滚动，表头纵向滚动时吸顶，横向滚动条保持在可视区域底部，“操作”列固定在右侧；支持切换、折叠、搜索、添加/编辑及导出当前筛选全部成员；数据只在当前页面会话内保存，刷新重置。成员“更多”支持“调整节点”和删除；编辑成员弹窗也提供同一个“调整节点”入口，两处均调用同一控制器和同一弹窗。
- 六个渠道均在“测试部门 / 测试1部”下提供“华东业务组、机构服务组、重点客户支持与运营组、区域客户跟进组”四个三级 Mock 节点。六个频道的 Mock 成员都归属到叶子节点，有子节点的父节点不直接挂 Mock 成员，使每个父节点的人数及成员集合严格等于所有直属子节点的去重并集。薄荷经纪人保留 24 名成员；频道首屏的示例成员 06、07、08、09 依次展示“人管、佣金、线索管理、线索跟进”身份。其余五个频道各提供 4 名成员，并全部落在叶子节点。左侧组织树、调整节点弹窗和批量导入目标节点树均读取同一份按频道隔离的 `departmentSets`，名称、层级、父子关系和完整路径保持一致；运行时新增、改名或删除的节点也会同步进入后两个选择器。该数据用于验证六频道切换、节点成员过滤、三级缩进、父级折叠、节点搜索、角色展示和成员调整，刷新后恢复。渠道根节点汇总本渠道所有下级成员，设置管理员时也可覆盖下级节点成员。
- 成员列表采用递归汇总范围：选择任一节点时展示“直接归属当前节点的成员 + 所有层级后代节点成员”。例如测试1部的结果包含自身成员和其下全部三级、更深节点成员，测试部门再汇总测试1部、测试2部及各自后代。成员搜索、当前筛选导出和设置管理员使用同一个递归范围；点击叶子节点时只显示该叶子直接归属成员。汇总结果全部在同一张表内连续展示，父节点的所有后代成员无需翻页即可查看。
- 调整节点弹窗展示成员姓名、域账号和当前节点，并在当前渠道内提供可搜索的完整组织树与节点全路径；当前节点禁选，标题与底部操作区固定，长节点列表只在弹窗中部滚动。确认后成员从原节点迁移到目标节点，并清理原节点保存的佣金和线索角色，不把旧权限带入目标节点。若成员具备原节点组织架构管理员身份，确认前增加二次风险提示；继续后移除原管理员身份且不自动成为目标节点管理员。完成后刷新当前成员表、显示成功提示，并在组织架构独立操作日志中新增“调整节点”记录，包含操作时间、操作人、当前渠道、原/目标完整路径、手动来源及管理员身份变化。
- 成员表在“姓名”后新增“身份”列，以 `20px` 高、`12px` 字号的紧凑标签按“人管、佣金、线索管理、线索跟进”固定顺序展示；同一成员可并列多个身份，无身份使用与表格其他字段一致的半角 `-`。身份直接读取设置管理员弹窗和成员编辑共用的角色状态，任一入口保存后立即更新；姓名列原有“管理员”标签继续使用原节点、原文字与原样式，“人管”仅是身份列中的角色简称。身份列参与表格内部横向滚动，不扩大配置页自身最小宽度。本地初始 Mock 在首屏第一名成员展示人管、佣金、线索管理，第二名成员展示人管、线索跟进，四类标签无需操作即可完整检查；管理员弹窗同步回显这些角色。线索管理与线索跟进互斥，因此单人合法上限为人管、佣金和一种线索身份共 3 个标签，当前列宽可在一行完整展示；标签容器仍允许换行，以兼容未来规则扩展。
- 添加成员与编辑成员弹窗复用同一角色状态：原“管理员”行固定按“组织架构管理员（人管）”“上级佣金归属人（佣金）”顺序展示两个复选项，文字保持单行；“线索”作为独立模块位于“转介绍人”下方，以单选方式展示“无”“线索管理员”“线索跟进人”和权限说明。线索选项直接复用转介绍人的 `typeGroup` 三项等宽布局、内边距与左对齐方式，不再单独居中。保存后与“设置管理员”弹窗双向回显，佣金 0/1 与两类线索互斥规则保持一致。
- 添加/编辑成员弹窗采用固定头尾结构：标题和关闭按钮位于固定头部，取消/确认按钮从表单滚动区移至弹窗内容的独立底部区域；只有中间表单滚动。头部、表单和底部通过纵向 Flex 分区，表单使用细滚动条并限制滚动链，避免长字段将关闭或保存操作滚出视口。
- 组织树首次进入只展开根渠道并展示一级部门，含下级的一级部门默认收起；用户手动展开后继续支持全部层级。成员表格只在确实向右横向滚动时显示左侧位置阴影，最左端不显示。当前渠道工具栏的设置管理员、导出Excel、添加成员保留原位置和左右对齐，统一为 `40px` 高、`14px` 文字和 `16px` 图标；前两项宽 `112px`，添加成员宽 `120px`。三枚图标从容器到 SVG 本体均固定为 `16px` 并采用零行高居中。渠道 Tab 当前态下横线与线上产品中心统一为 `71×4px`。
- 组织架构保留原顶部单行：六个渠道 Tab、搜索成员、批量导入成员和组织架构独立操作日志均位于 `64px` 顶部行。搜索最大宽度为 `333px`，可缩至 `120px` 以适配右侧入口；输入框保持 `64px` 通栏高度、左右 `1px` 边框、无上下边框和 `#2F3640` 的 `3%` 透明底色，hover、点击聚焦、输入与清空时边框和底色不变。批量导入紧邻操作日志，复用其文字按钮样式；两个入口均为 `14px` 文字、品牌绿图标和 `40px` 点击高度，默认深灰文字，hover/聚焦时文字转品牌绿，按下时文字与图标统一加深。操作日志图标画布为 `16px`，导入图标因原 Ant SVG 内部留白更大而使用 `19px` 光学校正，二者可见图形等大。搜索初始为空且未聚焦时不显示清除图标，聚焦或输入内容后显示，清空并离开焦点后隐藏。六个 Tab 不创建横向滚动容器。配置页不强制 `1228px` 最小宽度，表格保留自身横向滚动。表格身份、地区与转介绍人标签保持 `20px` 高、`12px` 字号和 `8px` 左右内边距，原颜色和内容不变。
- 组织树“⋮”复用原站菜单和图标：根部门提供添加子部门/设置管理员，子部门另提供修改名称/删除。部门名称校验空值与同级重名，按渠道隔离；删除需确认，包含子部门或成员时阻止删除。管理员选择与成员编辑共享本地成员状态。菜单点击不切换部门，支持外部点击、Esc、滚动和导航关闭。
- 成员表格工具栏左侧提供“设置管理员”按钮：直接克隆右侧“导出Excel”按钮结构，采用 `112×40px` 规格、同一水平线，并与表格左边缘对齐；视觉使用 `#2F3640` 黑底和白色文字。按钮 SVG 直接克隆部门菜单既有“设置管理员”图标，通过 `currentColor` 显示白色描边；点击将当前选中部门传给既有 `editDepartment(..., 'admin')`，与部门菜单打开同一弹窗和同一成员状态。
- 部门弹窗模板位于 `source-markup.js` 的 `departmentUi`，原始人员字段已清除；管理员列表以本地示例成员填充。日志按钮补齐原 SVG 的 viewBox，图标容器取消文字基线影响，保留原图形路径。
