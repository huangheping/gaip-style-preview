# 配置中心

## 入口与路由

- 入口：`配置中心.html`。一级菜单位于主导航末尾，可展开/收起。
- 一级父项与财富值中心共用 `gaip-main-menu-*` 契约，只展开/收起二级项，不改变 Hash；箭头固定在右侧 `16px` 并旋转，位置不随文字长度变化。配置图标默认态直接引用与线上构建包逐字节一致的 `features/config-center/assets/organization.svg`，当前态直接对同一 `<img>` 使用 CSS 滤镜，使图标与文字同步变绿；不在 JS 中手绘 path，也不依赖外部 SVG 蒙版。
- 注册表：`shared/config/channels.js` 的 `config`；`views` 为二级导航唯一来源。
- 组织架构：`#/workspace?gaip-channel=config&gaip-view=organization`。
- 操作日志：`#/workspace?gaip-channel=config&gaip-view=operation-log`。
- 沿用 Umi Hash SPA，地址栏文件名由共享导航同步，不加载新的文档。

## 页面实现

- 唯一源码位于 `features/config-center/`。`source-markup.js` 保存原站 DOM 模板（人员字段替换为示例）；`ant-source.css` 提供原站运行时组件基线；`config-center-content.css` 包含完整配置中心主体样式与本地内容覆盖；`config-center.css` 只包含主导航、顶部栏、顶部搜索和 Hash 页面挂载骨架；`config-center.js` 承载交互与挂载。`organization-source.css` 仅保留为未拆分的原站样式对照快照，不参与运行时加载。
- 原站 CSS 使用 `@scope (.gaip-config-page)` 限定范围。图标直接来自原站：`assets/organization.svg`、`folder.png`、`delete.svg`，其余原站内联图标保留，不重新绘制。
- 2026-08-31 根据参考站 `/web/config/organization` 核对：当前账号的配置中心只有“组织架构”二级项；“操作日志”为用户要求新增。
- 组织架构保留六个渠道（薄荷经纪人、Glory品牌顾问、外部机构渠道、线上渠道、小仓、荣耀经纪人）、部门导航、成员搜索/表格、Excel 导出与成员编辑入口。
- 本地组织根节点使用 24 名虚构成员，保留原站捕获的部门名称与层级；表格仍按每页 10 人分页，支持切换、折叠、搜索、添加/编辑及导出当前筛选全部成员；数据只在当前页面会话内保存，刷新重置。成员“更多”支持本地示例成员删除；线上权限分配未实现。
- 添加成员与编辑成员弹窗复用同一角色状态：原“管理员”行固定按“组织架构管理员（人管）”“上级佣金归属人（佣金）”顺序展示两个复选项，文字保持单行；“线索”作为独立模块位于“转介绍人”下方，以单选方式展示“无”“线索管理员”“线索跟进人”和权限说明。线索选项直接复用转介绍人的 `typeGroup` 三项等宽布局、内边距与左对齐方式，不再单独居中。保存后与“设置管理员”弹窗双向回显，佣金 0/1 与两类线索互斥规则保持一致。
- 添加/编辑成员弹窗采用固定头尾结构：标题和关闭按钮位于固定头部，取消/确认按钮从表单滚动区移至弹窗内容的独立底部区域；只有中间表单滚动。头部、表单和底部通过纵向 Flex 分区，表单使用细滚动条并限制滚动链，避免长字段将关闭或保存操作滚出视口。
- 组织树首次进入只展开根渠道并展示一级部门，含下级的一级部门默认收起；用户手动展开后继续支持全部层级。成员表格只在确实向右横向滚动时显示左侧位置阴影，最左端不显示。工具栏的设置管理员/导出/添加按钮文字和图标统一为 `16px`，渠道 Tab 当前态下横线与线上产品中心统一为 `71×4px`。
- 成员搜索采用红框参考布局：搜索框位于页面顶部频道栏内、“操作日志”左侧，最大为 `333×72px`，空间不足或新增频道 Tab 时继续弹性收缩至 `120px`；Tab 始终完整展示且不创建横向滚动容器，右侧操作日志入口不收缩。搜索与操作日志间距为 `24px`。输入框只显示左右 `1px` 边框，上下无边框，默认底色为 `#2F3640` 的 `3%` 透明度；hover、点击聚焦、输入与清空时边框和底色不变。搜索初始为空且未聚焦时不显示清除图标；聚焦或输入内容后显示，清空并离开焦点后隐藏。导出/添加按钮位于下一排右侧。配置页不再强制 `1228px` 最小宽度，表格保留自身横向滚动。表格身份、地区与转介绍人标签只缩小至 `20px` 高、`12px` 字号和 `8px` 左右内边距，原颜色和内容不变。
- 组织树“⋮”复用原站菜单和图标：根部门提供添加子部门/设置管理员，子部门另提供修改名称/删除。部门名称校验空值与同级重名，按渠道隔离；删除需确认，包含子部门或成员时阻止删除。管理员选择与成员编辑共享本地成员状态。菜单点击不切换部门，支持外部点击、Esc、滚动和导航关闭。
- 成员表格工具栏左侧提供“设置管理员”按钮：直接克隆右侧“导出Excel”按钮结构，保持 `147×48px`、同一水平线，并与表格左边缘对齐；视觉使用 `#2F3640` 黑底和白色文字。按钮 SVG 直接克隆部门菜单既有“设置管理员”图标，通过 `currentColor` 显示白色描边；点击将当前选中部门传给既有 `editDepartment(..., 'admin')`，与部门菜单打开同一弹窗和同一成员状态。
- 部门弹窗模板位于 `source-markup.js` 的 `departmentUi`，原始人员字段已清除；管理员列表以本地示例成员填充。日志按钮补齐原 SVG 的 viewBox，图标容器取消文字基线影响，保留原图形路径。
- 成员编辑和部门名称/删除/管理员弹窗的完整入口统一暴露为 `window.__GAIP_CONFIG_DIALOGS__`；正式页的按钮和全局弹窗预览均调用该控制器。预览模式会先挂载真实组织页状态，再执行同一表单填充、角色权限、事件和 `showModal()` 流程，不使用 `source-markup.js` 基础工厂单独伪造弹窗。
- “设置管理员”弹窗按多角色规则展示四组固定字段：组织架构管理员（人管，多选）、上级佣金归属人（佣金，0 或 1 人）、线索管理员（线索，多选）和线索跟进人（多选）。佣金组采用项目复选框视觉：选中一人后其余成员禁用，再次点击已选成员即可取消，取消后全部恢复，不提供独立清除按钮。同一成员可同时具备人管、佣金和一项线索身份；两类线索身份互斥。取消不写入状态，保存后按当前渠道/部门恢复。
- 配置中心二级页“操作日志”右上角的“导出Excel”按钮保持 `147×48px`，使用品牌绿底、白色文字和白色图标，hover/键盘聚焦时加深为 `#155347`。原共享日志图片图标在该页面内被替换为组织架构页“导出Excel”按钮逐节点克隆的 Ant 下载 SVG，文字也统一为“导出Excel”；共享操作日志组件在其他频道和弹窗中的 DOM 与样式不变。日志表头同步复用业务表格规格：`#F5F5F5` 底色、`#2F3640` 文字、`14px` 字号、`500` 字重和 `10px 16px` 内边距。
- 弹窗桌面宽度最大 `900px`，标题与规则说明下方采用左侧四个竖向角色 Tab、右侧单一成员面板和固定底部操作区。Tab 只显示角色名称和次级已选人数，不重复展示人管/佣金与单选/多选字段；当前项为通栏白底、黑色主文字和贯穿全高的 `#24D4C9` 左线。右侧头部不重复显示角色标题，也不使用绿色装饰线，只保留规则说明和更清晰的单选/多选标签；高度按内容自适应，上下 padding 均为 `16px`。支持点击或键盘切换，成员选择统一复用项目 Ant 控件。
- 操作日志调用 `__GAIP_OPERATION_LOG__.mount(host)`；共享渲染、筛选、分页、内容展开和 Excel 导出，不复制组件。页面与顶栏弹窗各自保留独立筛选状态，DOM ID 独立；离开二级页面销毁实例。
- 全局顶栏日志入口已移除；配置中心操作日志二级页和组织页右上角日志按钮保留，后者继续打开共享弹窗。所有日志仍是原有 28 条模拟记录，不捕获组织编辑行为，不是真实审计。
- 虚拟页面覆盖内容区域并将被覆盖的底层 Umi 业务内容子项设为 inert；退出时恢复。主框架节点重建后自动补挂；区域标记由 `channel-regions.js` 统一识别虚拟频道。
- 底层禁用只作用于被配置页覆盖的业务内容子项，不再禁用整个主内容节点。全局 AI Agent 悬浮入口保持原节点、原样式和原脚本，配置中心明确排除该节点的 `inert`/`aria-hidden`，离开配置中心时恢复底层内容原状态。
