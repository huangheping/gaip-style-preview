# 资讯中心

## 入口与路由

- 入口：`channels/news-center/index.html`
- Hash：`#/workspace?gaip-channel=news`
- 频道注册：`shared/config/channels.js`

## 唯一源码

- 样式：`channels/news-center/news-center.css`
- 页面主体、日期分组、文章卡片与详情 HTML：`channels/news-center/templates/`；`npm run build:templates` 生成 `templates.generated.js`，注册表和组件预览在交互脚本前加载它。
- 数据绑定与交互：`channels/news-center/news-center.js`；模板插槽不执行代码，用户数据继续由原有转义函数处理。
- 本地数据：`channels/news-center/news-center.js` 的开头数据段
- 图标：`channels/news-center/assets/`
- 海报分享：复用 `components/poster-share/global-poster-share.js`、`components/poster-share/global-poster-share.css` 和 `components/海报分享/`，不再引用仓库外的旧弹窗目录；工作台使用同一组件。

## 页面能力

提供资讯分类、精选筛选、关键词搜索、详情、分享及内容管理演示；工作台资讯模块的“查看全部”等入口通过 `window.__GAIP_NEWS_CENTER__` 打开该虚拟频道。

## 约束

- 继续复用工作台的 Umi Hash 路由，不触发整页刷新。
- 页面资源只从频道注册表预加载，不依赖新增的 `web/` 构建分包。
- 数据为本地 Mock，仅用于页面样式与交互演示。
- 详情打开时聚焦关闭按钮，关闭后聚焦当前列表中的文章按钮；避免列表重绘后焦点落在 body 导致 Esc 无法进入弹窗事件处理。
