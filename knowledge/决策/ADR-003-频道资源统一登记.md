# ADR-003：频道资源统一登记

## 决定

频道名称、路由、入口和专属资源统一登记在 `shared/config/channels.js`。频道代码存放在 `features/<频道>/`，由 `shared/scripts/channel-features.js` 预加载。

## 原因

根 HTML 是初始入口，不是页面源码。统一登记可以确保直接打开和 Hash 无刷新切换共享同一实现。

## 后果

- 禁止在多个 HTML 中复制频道 CSS/JS。
- 新增频道资源时必须更新频道配置。
- 修改后必须验证至少两个不同入口。
