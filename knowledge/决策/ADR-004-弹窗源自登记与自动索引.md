# ADR-004：弹窗源自登记与自动索引

## 背景

原弹窗预览同时维护 `弹窗源登记.js` 和 `弹窗预览.html` 的逐项打开分支。其他任务在频道源码中新增真实弹窗后，如果没有同步修改这两个位置，预览无法知道新增内容；重复维护也容易让源弹窗和预览入口失配。

## 决定

- 新增本地源码弹窗在真实源 JS 中使用 `@gaip-modal` JSON 块自登记，登记真实资源和同一个公开打开入口。
- `scripts/generate-modal-catalog.cjs` 扫描源登记并生成 `全局组件/弹窗自动索引.generated.js`。
- `shared/scripts/modal-registry.js` 是运行时唯一目录，负责合并既有基线和自动索引、校验唯一 ID，并执行通用 `invoke`。
- `弹窗预览.html` 不再按 ID 手写打开逻辑，也不保存弹窗 DOM/CSS。
- 可预览非抽屉弹窗必须在真实源登记 `category`：`information`、`form` 或 `confirmation`。预览页只按该字段生成三类目录和筛选，不另维护 ID 分类表。
- 预览父页只渲染轻量卡片与等高占位；卡片进入可见区域或用户主动加载时才创建隔离 iframe，避免首次打开同时初始化全部频道。
- 只读 `web/` 分包中的路由触发项和历史排除项暂留基线盘点；新本地弹窗不得继续加入手写基线。

## 约束

> [!warning]
> 纯 `file://` 页面不能枚举本地目录。自动发现发生在源码生成阶段，因此任何新增或修改登记块的任务必须运行生成器并提交生成索引；`--check` 和预览回归负责阻止遗漏。

抽屉继续不进入弹窗预览；GAIP Agent 主面板继续明确排除。无法从当前真实源码打开的项目不得用复制 DOM 或通用模板伪造。

## 结果

组织架构独立操作日志成为首个源自登记案例。其业务页面和预览都调用 `__GAIP_CONFIG_DIALOGS__.openOrganizationLog()`，源结构或 CSS 改动只维护一处。配置中心所有直接源弹窗在预览中共用空的样式作用域宿主，不再为了打开弹窗先渲染组织架构页面。
