# ADR-002：web 目录保持只读

## 决定

`web/` 保存原站下载的 Umi 主包、分包和静态资源，默认不直接修改、拆分、改名或移动。

## 原因

构建产物之间存在运行时映射和哈希依赖，直接修改难以维护，也容易破坏离线预览。项目自维护能力应放在 `shared/`、`features/`、`AI Agent/` 和 `assets/`。

## 例外

只有用户明确要求修复原构建产物，并确认无法通过扩展层解决时，才可修改；必须单独记录范围和验证结果。
